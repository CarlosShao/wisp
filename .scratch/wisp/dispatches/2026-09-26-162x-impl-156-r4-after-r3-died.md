## 6. Git 纪律

**只 commit、绝不 push**；禁 `--amend`／`reset`／`rebase`／`stash`／`checkout .`／`clean`／`rm`／任何删除；禁 `git add -A`／`git add .`／`git commit -a`。
提交形：`git add -- <显式路径>` → **`git diff --cached --name-only` 出现别人的路径就停手报回**（用了 pathspec 不是豁免）→ `git commit -q -F - -- <显式路径> <<'MSGEOF' … MSGEOF`（**定界符必须加引号**；含反引号的中文走 `Write`/`Edit`，别塞 heredoc 或双引号串——那会真的执行）。
"某节落在哪枚 commit"只认 `git log -L`／`git show --name-only` 现量。
