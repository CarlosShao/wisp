## 7. Git 纪律（违反任何一条＝退回）

- **只 commit、绝不 push。** 推送是编排者的。
- 每次提交**必须带显式 pathspec**：`git commit -q -F - -- <你的路径…> <<'MSGEOF' … MSGEOF`（**分隔符必须加引号**——不加引号的 heredoc 会把反引号里的东西**真执行**掉）。
- 提交前先 `git diff --cached --name-only`：**里面出现别人的路径是共享索引的正常噪声**（编排者今早就这样被兄弟程看见过一次），**不必停手**；但**提交之后**必须 `git show --stat <你自己那枚号>` —— **里面出现任何一枚不是你的路径＝停手报回**（这条才是判据）。
