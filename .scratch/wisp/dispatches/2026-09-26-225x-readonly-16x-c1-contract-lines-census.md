## 6. Git 纪律

**只 commit、绝不 push**；每次提交带**显式 pathspec** ＋ **加引号的 heredoc 分隔符**（`git commit -q -F - -- <你的两枚路径> <<'MSGEOF' … MSGEOF`；不加引号时反引号里的内容会被**真执行**）。
提交前 `git diff --cached --name-only` 出现别人的路径＝共享索引正常噪声、不必停手；**提交后 `git show --stat <你自己的号>` 出现别人的路径＝停手报回**。
**禁 `--amend`/`reset`/`rebase`/`stash`/`checkout .`/`clean`**；禁建 worktree。⚠ **本程一律不许跑任何删除命令**（见 §2）。
