## §4 诚实边界（先写在这儿，交件时补完）

1. "仍成立"是靠**静态尺**复认的：grep 命中的是"那句缺陷字面还在／那个函数还没被调"，
   **不是**"这功能不能用"的反证；运行期行为一律落"量不到"。
2. "已失效"必须给 commit 号＋`--name-only` 命中或今树 0 命中，二者都给不出就不许写这一档。
3. 界面侧（`frontend/**`／`design/**`）本腿禁读 ⇒ 凡判据落在那一面的票一律**量不到**，归口写"待可读前端面的腿"。
4. 四批的 `上次动过` 列是 `git log -1` 的**票文件**日期，不是缺陷产生日期。
5. 分桶件（`rate-census-*`）是 10-02/10-03 的读数，本腿只在"叠在桶号之上"的意义上引用，不判其过期。
