## 要修的两处

### 1. `internal/tools/fs.go:280-288` `joinForListing`（一处修七条：Test24R2A×4 + Test24R3×3）
现码（**已核**）：
```go
func joinForListing(dir, name string) string {
	if dir == "" { return name }
	if strings.HasSuffix(dir, `\`) || strings.HasSuffix(dir, "/") { return dir + name }
	return dir + `\` + name        // ← BUG：硬编码反斜杠
}
```
- **修法**：最后一行改 `return dir + string(os.PathSeparator) + name`（并把 `os` import 补上，如缺）。
- ⛔ 用 `filepath.Join`（D22 禁在 PathResolver 外用 filepath 做 FS 决策；且函数注释 :278 明令"must not grow into a general path joiner"）。
- 为什么 Windows 不回归：Windows 上 `os.PathSeparator == '\\'`，与原行为逐字节同。
- ⛔ 别改函数签名、别加 Clean、别动 C26 语义。

### 2. `internal/tools/launcher_other.go`（非 Windows 分支；Test22AppLaunchJobFailureSurfaces + Test22AUMIDIsWindowsOnlyHere）
- 先读这两个测试：`internal/tools/web_launch_test.go`（约 :122 与 :160）与 `launcher_other.go` 全文，弄清它们各自期望什么。
