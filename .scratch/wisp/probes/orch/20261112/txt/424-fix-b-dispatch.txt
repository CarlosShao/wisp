## ★修法（照做，已由编排者判定性质；⛔ 自己发挥改语义）

### 族 A：`configErrText`
- 现定义在 `cmd/wisp/resident_audio_windows.go:475`（windows-only 文件），**是纯函数**：
  ```go
  func configErrText(err error, c *config.Config) string {
      if err != nil { return err.Error() }
      if c == nil { return "config.LoadFile returned a nil config with a nil error" }
      return ""
  }
  ```
- **搬到跨平台文件**（新建 `cmd/wisp/config_err_text.go`，无 build tag，`package main`，import `config`），从 `resident_audio_windows.go` 删掉它。
- 调用点有 4 处：`logsink.go:224`、`memory_retention_180k.go:62`、`resident_audio_windows.go` 内 2 处——都在同 package，搬走后自动可见，无需改调用点。

### 族 B：3 个 `applyBall*` 包装 + 其 applier 变量
- 现状（都在 windows 文件）：
  | 符号 | 现在位置 |
  |---|---|
  | `var ballStyleApplier65 func(name string) bool` | `ball_style_65_windows.go:57` |
  | `func applyBallStyle65(name string) bool` | `ball_style_65_windows.go:71` |
  | `var ballIdleOpacityApplier func(v float64) bool` | `ball_idle_appearance_windows.go:64` |
  | `var ballClickThroughApplier func(on bool) bool` | `ball_idle_appearance_windows.go:68` |
  | `func applyBallIdleOpacity(v float64) bool` | `ball_idle_appearance_windows.go:84` |
  | `func applyBallClickThrough(on bool) bool` | `ball_idle_appearance_windows.go:93` |
- 包装函数体都是同一形状（nil 检查 + 调 applier）：
  ```go
  func applyBallX(...) bool { if <applier> == nil { return false }; return <applier>(...) }
  ```
- **把这 6 个（3 个 var + 3 个 func）搬进跨平台文件**（可放新建 `cmd/wisp/ball_config_appliers.go`，无 build tag，`package main`）。Linux 下 var 为 nil ⇒ 包装返 false，安全。
- **⛔ 不要搬** `installBallStyleApplier65`（`ball_style_65_windows.go:61`）与 `installBallIdleAppearanceAppliers`（`ball_idle_appearance_windows.go:72`）——它们接 `*ball.Ball`、赋真 applier，**留 windows 文件**。也⛔ 搬 `ballStyleSeed65`／`ballIdleAppearanceSeed`。
- 搬后 windows 文件里若有 import 变成未用，按 gofmt 清理最小集（只删确实未用的 import）。
