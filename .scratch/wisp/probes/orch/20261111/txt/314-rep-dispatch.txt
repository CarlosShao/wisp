### 第 2 步：★重复直跑 **5 次**（本腿的核心）

对 `$i in 1..5` 各跑一次，**每次都必须**：
- 用 `Start-Process -Wait -PassThru` 或 `& $exe *> file` 拿 **`$LASTEXITCODE`**
- **⛔ 不要用管道**（`| Out-File` 会缓冲丢尾，这正是 `full2.log` 不可信的原因）
- 每次独立日志文件：`run$i.log` / `run$i.err.log` / `run$i.rc.txt`

参考形状（照此写，勿改语义）：
```powershell
$exe = 'D:\tmp\wisp\20261111\314rep\wisp.test.exe'
for($i=1; $i -le 5; $i++){
  $out = "D:\tmp\wisp\20261111\314rep\run$i.log"
  $err = "D:\tmp\wisp\20261111\314rep\run$i.err.log"
  $p = Start-Process -FilePath $exe -ArgumentList '-test.v','-test.timeout=1800s' `
        -NoNewWindow -Wait -PassThru `
        -RedirectStandardOutput $out -RedirectStandardError $err
  $rc = $p.ExitCode
  # 转成十六进制便于认原生码
  $hex = '0x{0:X8}' -f $rc
  Set-Content "D:\tmp\wisp\20261111\314rep\run$i.rc.txt" "decimal=$rc hex=$hex"
  Write-Output "run$i rc=$rc ($hex)"
}
```

### 第 3 步：每次跑完立刻统计（**逐次都要算，不许只算最后一次**）

对每次 `run$i.log` 算这四项，**记进表格**：
1. 顶层 `=== RUN` 数（**剥掉含 `/` 的子测试**——不剥会得出 89 条这种假数，我踩过）
2. 顶层无判定行数（`=== RUN` 有、`--- PASS/FAIL/SKIP` 无）
3. 终点锚 `^=== RUN   TestZZ315A1` 命中数（满分 3）
4. `panic` / `fatal error` / `unexpected fault` / `ACCESS_VIOLATION` / `out of memory` 命中数

参考统计（照此写）：
```powershell
$c = @(Get-Content $out)
$runs = @($c | Select-String '^=== RUN   (\S+)' | ForEach-Object { $_.Matches[0].Groups[1].Value } | Where-Object { $_ -notmatch '/' })
$verd = @($c | Select-String '^--- (PASS|FAIL|SKIP): (\S+)' | ForEach-Object { $_.Matches[0].Groups[2].Value } | Where-Object { $_ -notmatch '/' })
$noV  = @($runs | Where-Object { $verd -notcontains $_ })
$anchor = @($c | Select-String '^=== RUN   TestZZ315A1').Count
$crash  = @($c | Select-String 'panic|fatal error|unexpected fault|ACCESS_VIOLATION|out of memory').Count
Write-Output "topRun=$($runs.Count) noVerdict=$($noV.Count) anchor=$anchor crashHits=$crash"
```

### 第 4 步：判读（**这是本腿的结论，必须明确写**）

| 退出码 | 含义 | 结论 |
|---|---|---|
| `0` | 全部跑完 | 该发正常 |
| `1` | 有测试红（**不是早停**） | 看 FAIL 名单 |
| `0xC0000005` | **访问违例**（原生崩溃） | ★真崩溃，需 dump |
| `0xC0000409` | **栈缓冲溢出** | ★真崩溃 |
| `0xC00000FD` | **栈溢出** | ★真崩溃 |
| `0xC0000135` | DLL 未找到 | ⚠ **环境问题，作废该次**，修 PATH 重跑 |
| 其他 | 记原值 | 不得归类为"崩溃"或"正常" |

**结论必须回答这三问**：
1. 5 次里几次 `0`、几次非 0？非 0 的原值各是什么？
2. 每次顶层 RUN 数是**固定同一数字**（确定性）还是**散布**（真间歇）？
3. 非 0 的几次里，`crashHits` 是否 >0？（>0 ⇒ 原生崩溃；=0 且 RUN 数少 ⇒ **逻辑提前返回**）
