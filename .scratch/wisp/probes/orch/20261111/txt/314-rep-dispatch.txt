## 第 2 步：★★直跑 5 次，取真退出码（本腿核心）

**⛔ 三个坑（我已实测，别踩）**：
1. `Start-Process` 之后 **`$LASTEXITCODE` 是空的** ⇒ 必须用 **`$p.ExitCode`**；
2. `$p.ExitCode` 对原生崩溃码返回**负十进制**（如 `-1073741819`）⇒ 必须 `'0x{0:X8}' -f $rc` 转十六进制再比对；
3. **⛔ 用管道接测试输出**（会缓冲丢尾）⇒ 必须 `-RedirectStandardOutput` / `-RedirectStandardError`。

```powershell
$exe = 'D:\tmp\wisp\20261111\314rep\wisp.test.exe'
for($i=1; $i -le 5; $i++){
  $out = "D:\tmp\wisp\20261111\314rep\run$i.log"
  $err = "D:\tmp\wisp\20261111\314rep\run$i.err.log"
  $p = Start-Process -FilePath $exe -ArgumentList '-test.v','-test.timeout=1800s' `
        -NoNewWindow -Wait -PassThru `
        -RedirectStandardOutput $out -RedirectStandardError $err
  $rc   = $p.ExitCode
  $hex  = '0x{0:X8}' -f $rc
  $code = if($rc -lt 0){ [uint32]$rc } else { $rc }
  Set-Content "D:\tmp\wisp\20261111\314rep\run$i.rc.txt" "decimal=$rc unsigned=$code hex=$hex"
  Write-Output "run$i decimal=$rc unsigned=$code hex=$hex"
}
```

## 第 3 步：每次跑完立刻统计（**逐次都要算**）

```powershell
$c = @(Get-Content $out)
$runs = @($c | Select-String '^=== RUN   (\S+)' | ForEach-Object { $_.Matches[0].Groups[1].Value } | Where-Object { $_ -notmatch '/' })
$verd = @($c | Select-String '^--- (PASS|FAIL|SKIP): (\S+)' | ForEach-Object { $_.Matches[0].Groups[2].Value } | Where-Object { $_ -notmatch '/' })
$noV  = @($runs | Where-Object { $verd -notcontains $_ })
$anchor = @($c | Select-String '^=== RUN   TestZZ315A1').Count
$crash  = @($c | Select-String 'panic|fatal error|unexpected fault|ACCESS_VIOLATION|out of memory|signal:').Count
$failBlk = @($c | Select-String '^FAIL$').Count      # ★ 框架自己的结尾块
$passBlk = @($c | Select-String '^PASS$').Count
Write-Output "topRun=$($runs.Count) noVerdict=$($noV.Count) anchor=$anchor crashHits=$crash failBlk=$failBlk passBlk=$passBlk"
```
⚠ **必须剥掉含 `/` 的子测试**——不剥会得出 89 条这种假数（编排者踩过）。

## 第 4 步：★判读（AC#0 要求的三种死法分类）

**退出码表**（用 `hex` 或 `unsigned` 比，⛔ 用负的 `decimal`）：

| hex | unsigned | 含义 |
|---|---|---|
| `0x00000000` | 0 | 全部跑完且全绿 |
| `0x00000001` | 1 | 有红 **或** 进程内 `os.Exit(1)` —— **必须靠下一步区分** |
| `0xC0000005` | 3221225477 | **native 访问违例** |
| `0xC0000409` | 3221225479 | **native 栈缓冲溢出** |
| `0xC00000FD` | 3221225725 | **native 栈溢出** |
| `0xC0000135` | 3221225781 | DLL 未找到 ⇒ **环境问题，该次作废重跑** |
| `0xC000013A` | 3221225786 | 被中断 ⇒ 该次作废 |

**★区分"跑完有红"与"`os.Exit(1)` 提前终止"（这是 AC#0 的核心，wrapper 层做不到）**：

| 观察 | 判定 |
|---|---|
| 退出码 `1` **且** `failBlk ≥1`（框架打印了 `FAIL` 结尾块）**且** 输出完整到最后一个测试 | **跑完有红** |
| 退出码 `1` **但** `failBlk = 0`（无框架结尾块）**或** 输出在某个 `=== RUN` 后戛然而止 | **★进程内 `os.Exit(1)` 提前终止** ← 最可能 |
| 退出码 `0xC0000005`/`0xC0000409`/`0xC00000FD` | **native 崩溃** |
| 退出码 `0` 但 `topRun` 远小于 616 | **★进程内 `os.Exit(0)` 提前终止** |
