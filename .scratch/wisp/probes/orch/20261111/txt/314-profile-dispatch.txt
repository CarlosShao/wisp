## 验证判据（三条，缺一不算完成）

### ① 编译门
```
$env:PATH = 'D:\work\workspace\projects plans\Wisp\build;D:\work\workspace\projects plans\Wisp;' + $env:PATH
go vet ./cmd/wisp        # 必须 rc=0
```
⚠ DLL 不入 PATH 会 rc=0xC0000135（DLL_NOT_FOUND），那是环境问题不是死法。

### ② 定点两发（撞车对）
```
go test ./cmd/wisp -count=1 -run '^(TestPanelHostRealWindowHopAndLifecycle|TestAC4FocusReturnToPriorWindowGap33r5)$' -v
go test ./cmd/wisp -count=2 -run '^(TestPanelHostRealWindowHopAndLifecycle|TestAC4FocusReturnToPriorWindowGap33r5)$' -v
```
两发都必须 rc=0。

### ③ ★整包 + 终点锚（**这一条是核心，四数不作数**）
```
Set-Location 'D:\work\workspace\projects plans\Wisp'   # ⚠ 必须先 cd 到仓库根
go test ./cmd/wisp -count=1 -timeout 1800s -v *> D:\tmp\wisp\20261111\314profile\full.log
```
然后**必须**检查：
```
$c = Get-Content D:\tmp\wisp\20261111\314profile\full.log
($c | Select-String '^=== RUN').Count                                   # RUN 数
@($c | Select-String '^=== RUN   TestZZ315A1').Count                    # ★终点锚，必须 ≥1
@($c | Select-String 'panic:|signal|killed|exit status').Count          # 必须 0
```
- **终点锚 0 命中 ⇒ 整包仍早停，判失败**，如实报（⛔ 拿四数说"跑完了"）。
- 历史教训（`A1717`）：早停与跑完**可以给出同一组四数**（RUN=418/PASS=325/FAIL=3/SKIP=1），因为没跑的那 192 枚本就不产生 `=== RUN`。
