## 五形（都能带着宿主自造的 TaskID 走到 Execute）
A  var req agent.ToolRequest; req.TaskID = "host-invented-id"; b.Execute(ctx, req)
B  type dispatch = agent.ToolRequest   →  字面量文本是 `dispatch{`，不是 `ToolRequest{`
C  req := agent.NewRequest()（字面量在别的包里）; req.TaskID = "…"
D  req2 := seed; req2.TaskID = "…"（拷贝既有值再改 id）

## 同一把尺打在这棵合成树上（他们 G1／G1b 的字面 pattern，引擎＝grep -rnE）
$ grep -rnE 'ToolRequest\{' --include='*.go' .
./agent/tools.go:17:func NewRequest() ToolRequest { return ToolRequest{} }
./host/host.go:9:// 形 1：零值 + 字段赋值（无 ToolRequest{ 字面量）      ← 命中的是注释文本
./main.go:12:	_ = host.LegitD(agent.ToolRequest{TaskID: "seed"})
⇒ A／B／C／D／E 五枚**宿主函数本身**没有一枚被 G1 吃到（C 吃到的是 helper 所在文件、D 吃到的是 main.go）。

$ grep -rnE '\.Execute\(' --include='*.go' .
host/host.go:13 / :20 / :27 / :34                                  ← A/B/C/D 全响（因为写成 b.Execute(）
⇒ **E 不在名册里**：`fn := (bridgeImpl{}).Execute` 后面没有 `(`，调用是 `fn(req)`。
