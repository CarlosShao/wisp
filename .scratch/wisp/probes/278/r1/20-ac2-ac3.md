## AC#3 `resident_windows.go` 那句歧义注释：不改码处置建议

### 现量原文（同一次取数拿到行号与短语，`git show HEAD:cmd/wisp/resident_windows.go | awk 'NR>=246 && NR<=259'`）

```
246: 	// Ticket 246 AC#7: the hop every earlier leg left open. The gate above can
247: 	// show a card, the ball above can veto one and step 3 above can refuse one on
248: 	// the way out - and AskOnTaskRoot / askConfirmation still had zero product
249: 	// callers, so nothing was going to raise one. This call is the caller: it reads
250: 	// the operator's console through interactiveStdin() (the same gate ticket 201's
251: 	// answer side uses, and the only one this process may test), assembles the task
252: 	// pipeline through cmd/wisp/run.go with ra's gate injected, and books the two
253: 	// D38(e) steps that entry owns (1 and 7). Every degraded branch inside it - no
254: 	// console, no config.toml, no credential - prints and returns nil, because the
255: 	// only condition that may stop this boot is the one ticket 128 settled.
```

那句 `This call is the caller` 落在 **`:249`**，而票 278 现量引的是 **`:248`** ⇒ 漂 +1（本腿禁 不改票面、禁 不改这句）。
文件射程具名：`resident_windows.go` 第 1 行＝`//go:build windows`，全文件 **288** 行。

### 两种读法各自成立的条件

- **读法甲（字面就近指代）**：把 `This call` 读成紧跟在 `:248` 那句宾语 `AskOnTaskRoot / askConfirmation` 上的「它的调用者」。
  ⇒ 成立条件＝`AskOnTaskRoot` 有产码调用者。**本腿尺给的是 rc=1（0 枚）**（见 `10-ac1-two-shapes.md` 尺 2）⇒ **这一读法在 HEAD 上不成立**；
  同句 `:248` 用**过去时** `still had`、`:249` 用**一般现在时** `is the caller`，时态差正是这一误读的来源。
- **读法乙（指本注释块所介绍的那一发调用）**：`This call` ＝ `:260` `src := startResidentTaskSource(rt, ra)`。
  ⇒ 成立条件有两个，本腿**都能证**：① 注释块 `:246` 起的主语一直是「Ticket 246 AC#7: the hop」，`:250-252` 描述的行为（读操作者控制台、经 `cmd/wisp/run.go` 装配、注入 `ra` 的 gate）**只在任务源那一侧成立**——`resident_task_source_windows.go:269 gate: ra.gate`、`:278 run, code := assembleRuntime(spec)`；
  ② 卡片今天真的举得出来，但走的是**工具调用**那一条（bridge→gate→`ballCardUI.Prompt`），禁 不是 `AskOnTaskRoot`。
  ⇒ 这一读法**成立**，只是「the caller」这枚词把「让卡有人来答的那一发」说成「那一枚函数的调用者」，是**措辞**歧义而非事实错误。

### 处置建议（禁 不改码，本腿一只字未动）

**建议档位＝「留档为主，改措辞要人批」**，理由分三层：

1. **留档**（零产码写面，本腿就能做的形状）：在真相源台账具名一句「`:246-259` 注释块的 `This call` 指 `:260 startResidentTaskSource(...)`，不指 `AskOnTaskRoot`」＋「`AskOnTaskRoot` 零产码调用者由 `10-ac1-two-shapes.md` 尺 2 现量 rc=1 钉住」。台账只追加、不删，符合规矩。
