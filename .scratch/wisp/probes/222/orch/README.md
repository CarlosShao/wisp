## 三条要跟着读数一起引的口径

1. ⚠ **`grep -c '^FAIL'` 是坏尺**：Go 的非 `-v` 输出里每枚失败包给**两行**（一行光秃秃 `FAIL`、一行 `FAIL\t包名\t耗时`），所以 `^FAIL` 会把 3 枚失败包数成 **7**。正尺＝`grep -P '^FAIL\t'` 或 `grep '^FAIL' \| grep -v '^FAIL$'`。**我第一次就报错过 7，纠正在此、原话不抹。**
2. ⚠ **`internal/risk` 在整包里那发 FAIL 没有复现**（单跑 ok 3.792s）⇒ 归因为**争用型假红**，制造者＝**我自己**：第一发 `-v`（后台）还在飞时我就起了第二发。命中名这一族在册（`TestResolvePerCallBudget`，台账 `A426`／`A432`）。⇒ **凡时间敏感量法要带复量**；⛔ 同时也不许反过来把真红一律说成争用。
