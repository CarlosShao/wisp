# 一次真机会话跑本（tickets 290 / 291 / 449 / 247）

**给谁看**：机主本人。他**不看代码**，只按步骤按键、说话、安静、回车。
**干什么**：一次约 **3 分钟**的会话，同时把四张票上「必须有人在机器前」的那几格采完。
**谁动手**：机主按 3 次（2 次热键 + 1 段说话）；其余全是脚本。
**三件产出**：
1. 本文件（步骤）；
2. `capture-once.ps1`（采集脚本，同级目录）＋ `levelprobe/main.go`（它调用的电平尺探针）；
3. `docs/evidence/s1/real-machine-once.md`（读数表骨架，跑完往里抄数字）。

**为什么用 PowerShell**（派单要求写理由）：这是 Windows 唯一的仓（D7 平台范围），
Windows 上**到处都有** `pwsh`/`powershell`，不需要 Git Bash、不需要 WSL；本仓既有的探针
（`.scratch/wisp/probes/**` 里那 100+ 枚）也清一色是 `.ps1`。`.sh` 在这台机器上要么靠
Git Bash（多一条装出来的依赖），要么靠 WSL（另一套文件系统、读不到 `%APPDATA%` 的
日志与 `D:\tmp`）。**读日志、算 mtime、找 pid、跑探针**这几件事在 PowerShell 里都是一等公民。

## 1. 步骤（照着按，按完按回车）

> 每一步都写明：**按什么 / 等几秒 / 采到哪几格 / 翻哪张票哪个框 / 跳过会缺哪格**。
> 格号（`290-2a` 之类）与 `summary.md`、`cells.json` 里的 `id` 一模一样，一一对得上。

### 第 1 步 — 按一次「静音热键」（约 10 秒）

- **按什么**：按一次**静音热键**（`config.toml` 的 `[hotkey] mute`；那一项为空就是用编译默认值，
  球启动那一行会印 `mute=… live`）。按完**等 2 秒**再按回车。
  - 忘了是哪个键？托盘右键菜单里的「静音」也能开门，但那样日志里的手势词会是 `tray-mute`
    —— **290 AC#3② 点名的 `mute-hotkey` 就采不到**了。所以这一格要用**热键**。
- **采到哪几格**：
  - `290-2a` = 日志里那行 `取消静音：设备已交接，采集线程在跑`（带 **文件:行号 + 时刻**）
  - `290-2b` = 同一行的 `gesture` 字段 = `mute-hotkey`
- **翻哪张票哪个框**：`290` 的 **`AC#3②`**（"用户能主动发起的一条开门路"）。
- **同时白拿一格**：`290-1a` = 本次进程**开机**那行 `capture armed but muted at boot; device not opened`
  ＋ `config_source`。这格不用按任何键，脚本从日志里读，翻 `290` 的 **`AC#3①`**（默认档不偷开麦）。
- **跳过这一整步会怎样**：`290-2a`、`290-2b`、`290-2d` **三格全缺**（表里写 `ABSENT`），
  且下面的真麦读数就**不是在"产品开门"的状态下取的**（探针自己开门，数字不受影响，但"产品门开着"这件事没有旁证）。
  跳过用 `-NoHotkey`。

| ④ `tone` | **什么都别说**：脚本自己用扬声器放 4 秒 1 kHz 音（0.5 满刻度） | 4 秒 |

- **采到哪几格**（每格都是 `samples / mean / max / span / levels_per_s`）：
  - `291-1`（形①安静）、`291-1b`（形①的对照窗）、`291-2`（形②说话）、`291-3`（形③外放音调）
  - `291-4`（形④**合成帧**：纯 DC 与 DC+正弦，走产码 `LevelOfSamples`，⛔ 不据此判生产）
  - `291-5`（形②与形①**能不能被既有判据分开**：`speak_mean > 2 × quiet_mean` 且 `speak_max > quiet_max`）
  - `449-a`（修后安静 `mean/max` ＋ 是否 `< 0.06`）、`449-b`（**同一帧**上 新尺−旧尺 的最大值，必须 ≤ 0）、
    `449-c`（今天这台机器的**直流分量** counts ⇒ 判定 0.368 能不能复现）、
    `449-d`（安静窗里**连续**低于门限的帧数，≥5 帧 ⇒ 球判定"没人说话"）
  - `247-a`（说话 vs 安静两个读数不同）、`247-c`（出处：采集/播放端点名、帧率、放音幅度）
- **翻哪几张票哪个框**：
  - `291` 的 **`AC#2`** ← `291-1`/`291-1b`/`291-2`/`291-3`/`291-4`/`291-5`
  - `449` 的 **`AC#8`** ← `449-a`/`449-b`/`449-c`/`449-d`

  `449-a`、`449-b`、`449-c`、`449-d`、`247-a`、`247-c` —— 见下面总表），

### 第 3 步 — 再按一次同一个热键（约 10 秒）

- **按什么**：**再按一次同一个静音热键**，把麦克风**关回静音位**（恢复出厂开机态），等 2 秒后回车。
- **采到哪几格**：`290-2d` = 日志那行 `已静音：采集已关闭，设备未打开`（证明**两个方向**都动了）。

- **⛔ 不要跳过**（除非你确定要一直开着麦）：跳过会让麦克风**停在开着的状态**，

## 3. 期望区间（从码里算出来的，⛔ 编数字）

所有算式都在这台机器上现算过；每一行给出**出处**，改码就得重算。

| 量 | 期望 | 怎么算出来的（出处） |
|---|---|---|
| 电平的定义 | `level = sqrt(mean((s-mean(s))²)) / 32768`，一帧 512 个 int16 | `internal/audio/level.go:119`（`LevelOfSamples`，票 449 落地后的定义：**先减本帧均值**） |
| 安静（纯直流） | **恰好 0** | 恒定帧的偏差为 0 ⇒ `MinLevel = 0`（`level.go:67`、票 449 AC#1） |
| 安静（有交流底噪） | **`0 < level < 0.06`** | 上界＝`SilenceLevelGate = 0.06`（`internal/ball/liquid.go:30`）；低于它球才判"没人说话"（`liquid.go:272` `if raw < SilenceLevelGate`）。下界＝任何非恒定帧都 > 0 |
| 安静的量级（**参考带，不是码推**） | `0.0013 – 0.0031` | 票 **449 AC#8** 的判据，来自 `f9b6d60f7` 的落地实测（施工图 `docs/evidence/s1/291-ac3-landing-table.md`）。**码推不出这个带**，码只推得出"< 0.06 且 ≤ 旧尺" |
| 参考带换成 counts | `42.598 – 101.581` counts | `0.0013 × 32768`、`0.0031 × 32768`（参考带 × `LevelFullScale`） |
| 旧尺的 0.368462 换成 counts | `12073.76` counts | `0.368462 × 32768` ⇒ 说明那 0.368 **就是一枚约 12074 counts 的直流偏置**；夹具 `12345` counts 读 `0.376739501953125`（`12345/32768`），与它差 2% |
| 门限 0.06 换成 counts | `1966.08` counts | `0.06 × 32768` |
| 最小非零读数 | `3.0517578125e-05` | `LevelLSB = 1/32768`（`level.go:72`，±1 LSB 方波） |
| 最热合法帧 | `0.999969482421875`（对称 ±32767）；`0.9999847412109375`（+32767/−32768） | `level.go:28-41`、`:74-77` |
| 形②要"分得开" | `speak_mean > 2 × quiet_mean` **且** `speak_max > quiet_max` | 票 **247 AC#2** 的既有 2× 门槛（`resident_audio_247_live_windows_test.go:194`）。**⛔ 这是既有判据，不许为了过而放宽** |
| 形③放音的理论 RMS | `0.353553390593274`（满刻度） | 脚本放的是 16 kHz 单声道 16-bit 正弦，幅度 **16384 counts = 0.5 满刻度** ⇒ `16384/32768/√2`。**麦听到多少是经验值**（扬声器音量/房间），码推不出 |
| 形④合成帧的闭式 | `0.129475118625466`（DC 12345 + 正弦 6000） | `6000/32768/√2`；容差 `SineLevelTolerance = 5e-5`（`level.go`），实测 `0.129476519242`，差 `1.4e-6`（票 449 AC#3） |
| 球判"安静"要多久 | **5 帧 = 160 ms** | `SilenceHoldMs = 150`（`liquid.go:31`）÷ `FrameIntervalMs = 1000/MaxAnimFPS`；一帧 32 ms ⇒ `150/32 = 4.69` ⇒ 第 5 帧才够。`449-d` 数的就是"最长连续低于 0.06 的帧数" |
| 为什么每形要 ≥3 秒 | 包络的释放时间常数 420 ms ⇒ 3 秒 = **7.14 个 τ**，误差 `e^-7.14 ≈ 0.08%` | `LevelReleaseTauMs = 420`（`liquid.go:33`）⇒ 3 秒足够让球的包络收敛到原始电平，短于它就是读"还在爬"的中间值 |
| 新尺必须 ≤ 旧尺 | `new ≤ old`，**只有本帧均值为 0 时取等** | 数学事实：均值是平方偏差的最小点 ⇒ `Σ(s-mean)² ≤ Σs²`。`449-b` 量的是实测最大差值，应该 `≤ 0` |

**两条实测提醒**（2026-11-14 用本脚本自测时都撞到过，真跑也会撞到）：

1. **安静窗的 `max` 可能远高于 `mean`**（自测：`mean=0.0014`、`max=0.0822`，一声碰键就过 `0.06`）。
   判决看 `mean` 与 `449-d` 的**连续帧数**；尖峰照实记（"某一帧瞬时噪声"），⛔ 不许抹平，
   ⛔ 也不许因此说尺坏了。
2. **今天这台机器可能没有直流底噪**（自测 `dc_mean ≈ -0.1 counts`）⇒ 票面 `0.368462`
   （≈`12073.76` counts）**复现不出来**。这时 `449 AC#8` 只能按"同一窗 `new ≤ old` ＋ `mean < 0.06`"判，
   并把"0.368 不可复现"**具名**写进结论（票 291 的 `mic` 腿 2026-11-08 已经报过一次同形）。

## 4. 纪律（贴在墙上）

- ⛔ **启停产品进程**：关球、重启球、开第二个球、给球发信号 —— 全禁。脚本对产品只有两种动作：**读 pid**、**读日志**。
- ⛔ **改任何东西**：产码、`config.toml`、阈值、golden、`thresholds.go`、`docs/specs/**`、`frontend/**`、`design/**` 一字不动。脚本的写点只有 `D:\tmp\wisp\<日期>\realonce*\`。
- ⛔ **`git add -A` / `--amend` / `reset` / `rebase` / `stash` / `checkout .`**、⛔ **push**。
- ⛔ **不许把"球已经跑了多久"当判据**：判据只用**日志行号 + 文件 mtime + pid**。
- ⛔ **不许补零**：没采到就 `ABSENT`，并在 `note` 里写原因（哪一步跳了、哪枚文件不在、mic 没开）。
- 采完之后**别删**任何目录（重跑会开新目录，旧的留着）。
