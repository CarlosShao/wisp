## 4.1 M1＝票面点名的那一形："分叉时顺手清理"
在 `ForkSession` 复制完轮次之后、事务返回之前插一条 `DELETE FROM session_turn WHERE session_id=?`（打的是 parentID）。

红句逐字（连文案，`go test ./internal/session/ -run TestSessionFork -v -count=1`，`M1_SESSION_RC=1`）：
```
=== RUN   TestSessionForkDoesNotSwallowOriginal
    manage_test.go:213: original lost turns (2 -> 0): the fork swallowed history
--- FAIL: TestSessionForkDoesNotSwallowOriginal (0.06s)
FAIL
FAIL	github.com/CarlosShao/wisp/internal/session	0.089s
FAIL
```
⇒ 这一发**牙是真的**：`manage_test.go:212-214` 那条"原件轮数少了就 Fatalf"直接把"顺手清理"钉死，
后面的逐枚比对 `:215-219`（`before[i].ID/Seq/Content` 三字段）与父行 `:220`（`Title=="orig" && ForkedFrom==""`）是第二层。

## 4.2 M2＝反向那一形："分叉只开个新头、不带走历史"
把复制那一句的 `WHERE session_id=?` 后面加 `AND 1=0`（父行父轮一枚不动，分叉带走 0 行）：
```
=== RUN   TestSessionForkDoesNotSwallowOriginal
    manage_test.go:226: fork turns = [] (<nil>), want 2
--- FAIL: TestSessionForkDoesNotSwallowOriginal (0.05s)
FAIL
```
⇒ 同一枚用例还钉住了"分叉必须带走历史"（`:224-227`）。
另有一条"带走的是复制、⛔ 搬家"的断言在盘上（`:232-234` 比 `forkTurns[i].ID == before[i].ID` ⇒ 复用父行 rowid 就红），
**本腿⛔ 为它单独做发突变**（要造它得让 `session_turn.id` 改成显式复用，超出"顺手清理"那一形）⇒ 这一条本件只交"断言在"，⛔ 交"牙验过"。
