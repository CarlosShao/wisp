## 2. 于是"这枚勾"在契约里是什么地位

三段拼起来（每段都有上面的行号凭据）：

1. **菜单里有"静音"这一项**＝契约许了（`SPEC-08:229`）。
2. **这一项带一枚勾**＝契约**没许**（8 枚字样名册 × 两份指定文件 × 全 spec 目录，⛔ 零命中）。产码里这枚勾是**自造的一层**：`internal/ball/tray_windows.go:79-91` 的 `appendItem(id, label, checked)` 对四项都收 `checked`，其中"打开面板"（`:86`）与"退出"（`:91`）传字面量 `false`，只有"静音"（`:88`）与"暂停唤醒"（`:89`）传变量——⇒ **代码的形状在等一座镜像**，而契约从未说这座镜像该连到哪。
3. **"静音状态该让用户看见"**＝契约许了，但**许的面是球**（灰球＋斜杠，`PLAN.md:1312`／`PLAN.md:3553`／`SPEC-08:62`／`SPEC-04:47`）。⚠ 而球那一面**今天同样没有交付**，且本票不许动它：`cmd/wisp/resident_ball_windows.go:49-51` 逐字
   ```go
   // What did NOT change here: no state machine event is dispatched (D43's
   // Sleeping -> Muted edge does not exist, and inventing one is a human-approved
   // contract change, not a wiring detail), and no second "am I muted" flag.
   ```
   ⇒ 也就是说：**契约许诺的那一面（球）卡在一枚需要人工批准的 `A##` 上**（票 293 `AC#3` 已重述："表里没有 `Sleeping → Muted` 那条边"），而**没被许诺的那一面（托盘勾）反而是今天唯一可能立刻让用户看见静音状态的界面**。这一句是本腿交给编排者的**核心张力**，⛔ 不是本腿的决定。
