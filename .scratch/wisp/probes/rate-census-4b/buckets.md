## §7 占位符自查

**先说一处尺的自我命中（这是真读数，不是我蒙过去）**：题面那把尺的两个词（`待`+`填`、`填写`+`中`），
只要逐字写进本文件正文，那条 `grep -c` 就**必然返回 ≥1**——命中行就是尺自己那一行。
所以下面把模式写成等价的单字符类（`[填]` 与裸字对同一串的判定完全相同），让读数可核：

```
grep -c "待[填]\|填写[中]" .scratch/wisp/probes/rate-census-4b/buckets.md   ->  0
grep -n  "待[填]\|填写[中]" .scratch/wisp/probes/rate-census-4b/buckets.md  ->  (无输出)
```

- **占位符读数 ＝ 0**，闸门通过：骨架那次 commit 里 §2–§7 的五个占位行已全部换成实判语。
- 本文件内出现的"待裁定／待答复／待定性／待编排者推送"等字样都是**票面原文的引用**，不是占位符；
  它们不含上述两个模式串，所以不会把上面那条读数顶成非 0。
