## 这是什么（人话）

你在跟 Wisp 说话，每说一句，它都会把这句话存进那次对话的记录里。可是"这次对话排第几"看的是**它上一次被动过的时间**，而"存一句话"这一步**没去更新那个时间**。
结果就是：你在旧对话里聊了半天，列表上它⛔ 不会跳到最前面；你要找它，还得往下翻。
今天唯一会把它顶上去的动作是**改名、归档、分叉**——都是"你手动折腾它"，⛔ "你在用它"。
