## 为什么这不是"少了一行 defer"

两件事本票要分开判，别混着修：
- **有没有资源／语义在长**：任务结束后那枚 scope 留在表里 ⇒ 长跑的常驻腿会**一路加不减**。它的实际后果边界（内存？判定？同名复用？）**验收程与实现程都没量到就不许说"只是难看"**，也不许说"泄漏很大"——**两侧都不许凭感觉报数**（这条我特意写死，因为我自己现在就没量）。
- **有没有判定被污染**：`CloseTask` 的语义若是"这一轮的污点结论作废"，那**不关**就意味着**下一轮可能读到上一轮留下的污点状态**。⇒ 那一发如果成立，属**跨任务串味**，比内存优先级高得多。
  ⚠ **这一问就是本票的硬核心（AC#2），不许用"看起来不严重"收。**
