## 这是什么（人话）

系统里有一条已经写死的规矩：**一次工具结果超过 4000 token，就只把"头 500 ＋ 尾 200 ＋ 总长度 ＋ 一个文件路径"塞进模型的上下文，全文另外存成一个文件**（`PLAN.md:431`）。那条契约文字接着说：模型想要全文，**可以拿"读文件"那枚工具自己按需要再读**。

问题在下一句：`fs.read`（读文件那枚工具）**只能读用户明确授权过的目录**，而那份授权名单**出厂默认是空的**（`docs/specs/SPEC-03-config-secrets-envs.md:35` 逐字：`allowed_dirs[]=[]`）。而我本轮现读的三行码说明**那个"另外存成文件"的目录，从来没有被自动加进名单**：

- 〔我本轮现读过〕`cmd/wisp/run.go:327-331`：授权根**只**从 `cfg.FS.AllowedDirs` 逐条拷进来，没有第二路来源。
- 〔我本轮现读过〕`cmd/wisp/run.go:609`：spill 落盘的目录是 `filepath.Join(rt.spec.dataDir, "artifacts")`——**同一个 `dataDir` 没有任何一行码把它加进上面那个 `allowed` 列表**。
- 〔我本轮现读过〕`internal/tools/paths.go:50-52`（那句函数注释逐字）：`An EMPTY allowlist authorizes nothing: every fs call lands at L2 (R2)` —— 名单空＝什么都判到 L2（要人工批准），不是"那就放行吧"。

⇒ **今天"全文见 X"这句话，是在给模型指一条它自己走不通的路**：要么被拒（要人来批），要么在最默认的界面下连批都批不了。而**票 164 刚落的 `task.output` 用的正是同一句许诺**（它把 `ArtifactPath` 原样写进回执，且**没有问过"这条路径在不在授权根里"**）——所以这不是旧账，是**新码正在把这句空话抄下去**。

## 为什么值得做／不做的后果

不做的后果：**本仓最看重的那件东西——"对外说的话要能兑现"——在这一条上已经是假的**，而且假得很安静：回执里没有一句"这条路径你现在读不到"，模型会照着指的路去撞一次墙，然后把那堵墙当成自己的错误。更坏的一支是：下一程为了让 `fs.read` 能读回 artifacts，**顺手把 `dataDir` 加进授权根**——那是一次**安全范围的放宽**（那个目录里躺着 `config.toml` 与 `secrets\`，`cmd/wisp/run.go:104` 的注释逐字写着这条），而它会在一个跟安全毫无关系的交件报告里被当成"顺手让测试变绿"混过去。⇒ **本票把这件事从"下一程的临场判断"变成"owner 必须先说的一句话"。**
