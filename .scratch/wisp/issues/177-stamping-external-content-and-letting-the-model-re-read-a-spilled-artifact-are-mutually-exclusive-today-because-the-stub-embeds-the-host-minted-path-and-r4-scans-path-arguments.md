## 这是什么（人话）

我们有两件都想让它成立的事：

1. **凡是外来的内容，进上下文之前要盖"这是外来的"戳**（防被人塞话骗模型；票 175 要补的就是漏掉的一枚）。
2. **一次结果太长时，全文落到一个文件，上下文只留头尾＋总长＋那条路径，模型想看全文可以自己去读**（`PLAN.md:431`，已经冻结在契约里，也是票 164 AC#3 的判据）。

撞车撞在第 2 件的设计上：**那条路径是写在桩文本里的**（`task.go:229` 逐字 `…全文见 %s…`）。所以一旦第 1 件真的执行——把这段"外来的输出"连桩一起盖戳——**那条路径本身也进了污染索引**。而模型接下来最自然的动作就是拿**这一条路径**去调 `fs.read`，此时：

- 它的参数**只有那条路径**；
- 污染检查对"路径类参数"**不豁免**（`internal/risk/provenance.go:662` 那一支，`175-r1` 现读：只有非路径键才跳过）；
- ⇒ 命中 ⇒ R4 升 L2 ⇒ 而 R4 那一档**按规格连会话授权都不吃**（`SPEC-06:37` 逐字），测试里没接审批通道，就直接"已拒绝执行"。

⇒ 结果：**"读回来要盖戳"和"续读不许出卡"这两句，今天不能同时为真。** 这不是选形问题：实现程把最宽那形（凡成功结果都盖戳）做成变异跑了一遍，红的更多（5 枚，含票 158 自己的反向对照）；换窄形（只加 `task.output`）红这 2 枚；**三支候选形都撞同一格**。⚠ **实现程没有为了变绿去放宽那两枚断言**——这一点我做对了派单，它守住了。
