## 这是什么（人话）

撞车撞在第 2 件的设计上：**那条路径是写在桩文本里的**（`task.go:229` 逐字 `…全文见 %s…`）。所以一旦第 1 件真的执行——把这段"外来的输出"连桩一起盖戳——**那条路径本身也进了污染索引**。而模型接下来最自然的动作就是拿**这一条路径**去调 `fs.read`，此时：

- 它的参数**只有那条路径**；
