## 形状要说清（这是判据，不是背景）

`runGitIndex` 问 git 三次（`rev-parse` / `ls-files -z` / `ls-files -z -i -c --exclude-standard`）。
后两次是**两条独立命令**，所以它们之间若有人提交：

- `all`（第一读）可能**缺**那枚新变的目录；
- 于是 `holds(dir)=false` ⇒ 该目录对 `skip()` 而言不再"受追踪" ⇒ **一枚 ignore 规则把它吞掉**，门**少扫**且不报错。

文件那一支反过来不成立（所以验收量到 `holds(file)=true`）：`-i -c` 只报 git 自己认为匹配的，多出来的目录条目不会让它多报。
⇒ **单向的少扫**，这正是这仓最难查的那一类（"门是绿的"就是它的表现形式）。
