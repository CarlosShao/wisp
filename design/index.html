Wisp
一缕 · 前端原型 · Design Prototype

轻量级语音 Agent 悬浮助手。本目录是纯静态视觉原型—— 零构建、离线可用、双击即开。生产实现中悬浮球是 Win32 分层窗口 + Direct2D 自绘， 面板是按需拉起的 WebView2；两者共用同一份设计 token（契约 C21）。

原型阶段的边界（方案 §17.9 / M0 元要求）： 不接真实数据、不做路由、不做响应式（面板固定 640px）、不做无障碍树（S5 靠 Radix 拿）、不做 i18n（中文硬编码）。 本页不含任何 emoji—— 所有图标都是内联 SVG（§17.4），包括 agent 的思考中、流式输出、工具调用等状态。

「简约但高级」的八条硬规则
高级感来自可执行的决定，不来自「做得精致一点」。方案 §17.3。
Rules
低饱和配色
所有功能色降饱和。绝不用纯红纯绿纯蓝，也不用 Tailwind 默认的 red-500 / green-500 —— 它们在暗底上显得廉价。见下方色板。
靠 1px hairline 边框分层，不靠重阴影
三档边框（hair 0.07 / soft 0.11 / strong 0.18）承担绝大部分层级表达。box-shadow 只用于悬浮层，且必须是双层（1px 描边色 + 大范围极淡扩散）。
精确的间距阶梯
4px 网格，只用 2 / 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64。不得出现 15px、18px 这类值 —— 不一致的间距是「业余感」最快的来源。
字体排印是主要视觉手段
七档字号阶梯，强对比；数字一律 tabular-nums；字重只用 400 / 500 / 600；section label 用 micro 大写字母 + 0.06em 字距 —— 这是 Raycast / Linear 那类质感的核心手法。
克制的动效
120 / 180 / 260ms 三档，单一缓动曲线 cubic-bezier(0.32, 0.72, 0, 1)。禁止 bounce、elastic、超过 300ms 的 UI 动效。循环动画只允许出现在非空闲态（SLO 约束）。
大量留白
面板固定 640px 宽，正文行高 1.6，卡片内边距不小于 16px。信息密度靠排印层级压出来，不靠把元素挤在一起。
零 emoji，全部内联 SVG
Lucide 同源 stroke 图标，24×24、stroke-width 1.5、round cap/join，尺寸只用 14/16/18/20 四档，颜色一律 currentColor。也禁用对勾、叉号、警告、箭头这类文字符号（一律换成内联 SVG），以及 sparkles / wand / brain / robot 这四个「AI 俗套」图标。
中文排版的两条专属约束
字号下限 14px（12px 中文在 Windows 上笔画粘连，micro 11px 只用于英文大写 label 与纯数字）；禁用 300 及更细字重（Windows 中文细体发虚）。忽略这两条会得到「高级但难读」。
