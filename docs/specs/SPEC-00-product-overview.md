# SPEC-00 · 产品总纲与用户故事

> 追溯：PLAN.md 全文（D1–D47）；开发方是 AI Agent（D22/D23），本 spec 同时服务于人与 agent。

## 1. 问题陈述（Problem Statement）

用户希望在 Windows 桌面上有一个**语音驱动的通用助手**：随叫随到、干完就走——能听懂中文口语、
能操作本机（文件/应用/系统设置）、能上网查资料、能口述成文、能陪聊，且**不用的时候真睡着**
（不占内存、不占 CPU、不开麦克风）。现有产品全部不满足：

- 各类桌面 AI 宿主（DSH 系桌面变体）**全都没有语音能力**（D21 已逐仓 grep 证实）
- 常驻型助手空闲即吃 100MB+（Tauri/Electron WebView 常驻），违背「不用就睡」
- 语音助手普遍**默认常开麦克风**，隐私上不可接受
- 有语音能力的产品没有**本机操作 + 权限门控**（要么能干但危险，要么安全但残废）

## 2. 解决方案（Solution）

**Wisp（一缕）**：单常驻 Go 进程承载的悬浮球语音 Agent。

- **轻**：空闲态进程树私有内存 ≤25MB（D32），无 WebView、无动画、无网络长连接；
  工作态按需拉起 WebView/模型，回落 10s 内归还内存（C11 强制 `debug.FreeOSMemory()`）
- **听与说**：本地 sherpa-onnx 全链路（KWS 唤醒 3.3M / VAD / 流式 ASR / 标点 / TTS），
  半双工杜绝自激（D16）；默认不开麦克风（隐私三件套）
- **称职**：30+ 内置工具（D34 权威表）+ Tier1 声明式插件 + Tier1 command 插件（D46，可包任意
  本机 CLI 如 lark-cli/git/ffmpeg）+ Tier2 goja 插件（默认关闭）——覆盖「系统操作 / 信息查询 /
  口述成文 / 陪聊」四场景
- **安全**：L0/L1/L2 三级门控（D4）+ 中心风险推断 R1–R9（C19）+ 路径规范化唯一入口（C26）+
  污染追踪（C25）+ 间接提示注入五层防御（D30）+ 审批队列（C18）
- **可见**：悬浮球 20 态状态机（C12/D43）+ 按需 WebView 面板（命令/结果/配置/历史/取证/成本），
  每次工具调用可查（`tool_call` 表 30 天）

## 3. 用户故事（User Stories）

### A. 唤起与语音交互

1. 作为用户，我想要**唤醒词**免手唤起助手，以便双手忙时也能呼叫它（KWS opt-in，D2/D5）
2. 作为用户，我想用**全局快捷键或单击悬浮球**唤起，以便不开唤醒词也能零成本使用（D9）
3. 作为用户，我想要**说「停/取消/重说/大声点」立即生效**（本地正则，不经 LLM），以便随时纠偏（D11）
4. 作为用户，我想要 **TTS 播报期间麦克风自动关闭**，以便它不会被自己的声音误触发（D16 半双工）
5. 作为用户，我想要在播报时**用快捷键或点击打断**，以便不用等它说完（D16 打断通道）
6. 作为用户，我想要**一键全局静音**（快捷键），以便随时彻底闭麦（D16 隐私三件套②）
7. 作为用户，我想要唤醒词激活时**悬浮球有常亮可见指示**，以便始终知道麦克风是否在听（D16②）
8. 作为用户，我想要**多轮对话保温**（`Warm` 态：模型热、麦克风关），以便第二轮回复不用重等模型加载（B4/C31）
9. 作为用户，我想要**显式开启连续对话模式**（红色常亮环强提示 + 首次 L2 隐私确认），以便陪聊时免每轮按键（§15 第 5 项定案）
10. 作为用户，我想在语音不可用（噪声/故障）时用**文字输入与命令面板**完成同样的事，以便语音故障不影响可用性（D9 硬性质）

### B. 执行能力（称职助手）

11. 作为用户，我想说「打开记事本 / 打开系统设置的蓝牙页」，以便语音完成系统操作（`app.launch`/`file.open`，D34）
12. 作为用户，我想说「把下载目录里的 PDF 归到一个文件夹」，以便文件治理（`fs.*`，目录白名单内）
13. 作为用户，我想说「把这个文件丢回收站」且它是 L1 低门槛操作，以便整理文件不被确认轰炸（`fs.trash`，D34）
14. 作为用户，我想说「音量调到 30% / 锁屏 / 切到浏览器」，以便控制系统（`system.*`/`window.*`，D34）
15. 作为用户，我想说「查一下 X 的最新版本 / 搜一下这个错误码」，以便信息查询（`web.search`，D23）
16. 作为用户，我想说「打开这个链接给我总结 / 读一下这个 PDF 的第三章」，以便内容消化（`web.fetch`/`doc.read`）
17. 作为用户，我想说「看看我屏幕上这个报错是什么」，以便它截屏看懂我的屏幕（`screen.capture` + C7 Image 部件）
18. 作为用户，我想**连续口述 300 字直接出现在目标应用光标处**（含标点恢复），以便口述成文不用再粘贴（`input.type` + P4）
19. 作为用户，我想让长结果**自动落文件并播报摘要与路径**，以便代码块/表格这类没法听的内容可回看（D10 分流）
20. 作为用户，我想让短结果**同时写进剪贴板**，以便直接粘贴使用（D10 第 4 档）
21. 作为用户，我想说「20 分钟后提醒我……」，以便获得一次性提醒（`reminder.*` 窄例外，16.5.4）
22. 作为用户，我想通过**Tier1 command 插件用语音驱动 lark-cli 查日程/发消息**，以便邮件/日历/IM 不内置也能力完整（D46 + §15 第 10 项定案）
23. 作为用户，我想给 git/ffmpeg/docker 等本机 CLI 各写一份**声明式清单**就能语音驱动，以便零 Go 代码扩展能力面（D46）
24. 作为用户，我想在 TOML 里显式开启 `shell.exec` 后用语音跑任意命令，以便技术场景不被捆住手脚（D14/D33）

### C. 安全与确认

25. 作为用户，我想让只读操作（查询/搜索/读文件）**不打断直接执行**，以便高频操作零摩擦（L0，D4）
26. 作为用户，我想让可逆写操作（新建文件/存草稿）在**2–3 秒执行前阻止窗口**内可一键否决，以便误识别不至于成事（L1，D4/B1）
27. 作为用户，我想让不可逆操作（删除/覆盖/关机/外发/注入输入）**必须显式强确认**，以便语音误识别永远到不了不可逆那一步（L2，D4）
28. 作为用户，我想让 L2 的**「允许」只出现在原生侧**（点悬浮球/原生确认卡/快捷键），以便面板被注入 XSS 也拿不到批准权（D33/F2 + §15 第 6 项定案）
29. 作为用户，我想让批量操作（500 个文件的整理）**合并为一次确认**（显示总数与影响面），以便不被 33 分钟确认轰炸（D45-1，解 B2）
30. 作为用户，我想在确认卡上选择「**本会话内允许此工具于此路径模式**」，以便同类重复操作只确认一次且会话结束自动失效（D45-2）
31. 作为用户，我想让「读过本地文件再外发」这类**组合操作自动升级强确认**，以便提示注入链走不通（C25/D30①）
32. 作为用户，我想让 `~/.git-credentials`、`.git/config`、产品自己的 `config.toml` 等**永远不可读**，以便任何配置放宽都救不了凭证泄露（A 档黑名单，F1）
33. 作为用户，我想让**审批超时一律判拒绝**（300s）且任务可一键重放，以便我走开后系统不会自作主张（C18）
34. 作为用户，我想在面板「安全」页看到**所有生效中的会话授权并可一键撤销**，以便授权永远在掌握中（D45-2）
35. 作为用户，我想看到悬浮球上的**审批队列深度角标与排队任务**，以便知道它在等什么而不是卡死了（D31 可视化强制）

### D. 记忆与陪伴

36. 作为用户，我想让它**记住我说过的高频事实**（家人称呼、喜好、作息），以便陪聊时它懂我（L1 画像，D20）
37. 作为用户，我想在它记住一条时看到**「记住了：X」短闪 + 一键撤销**，以便记错可以立刻纠正（D20 反馈）
38. 作为用户，我想说「记住……」建立**显式记忆**，以便长尾偏好可存取（L2，D20）
39. 作为用户，我想在面板里**逐条查看/删除/导出**画像与记忆，以便隐私是透明可控的（D20/D35）

### E. 成本、配置与可观测

40. 作为用户，我想看到**每个任务的 token 与费用、日/月累计**，以便知道它烧了多少钱（C23）
41. 作为用户，我想设定**日/月费用预算**，达限告警或暂停，以便费用失控前被拦住（C23）
42. 作为用户，我想用 **GUI 编辑配置**且它就是 `config.toml` 的可视化编辑器，以便单一真相源没有双状态 bug（D6）
43. 作为用户，我想让**安全相关配置的放宽必须强确认**，以便一次提示注入改配置文件无法给自己提权（D36）
44. 作为用户，我想**首次使用某能力时自动下载对应模型**（校验签名、断点续传、进度可取消、可指向本地目录），以便不被几百 MB 下载卡死（D26/C29）
45. 作为用户，我想在出问题时**一键导出诊断包**（先审查再发送，不含音频/Key/转写全文），以便报 bug 不用交代隐私（§5.1/§14.4）
46. 作为用户，我想让**内存泄漏被看门狗自动兜住**（按态查表卸载、回落失败告警、一键重启），以便长期常驻不劣化（D18/D32）

### F. 可靠性与生命周期

47. 作为用户，我想让它**单实例**运行（二次启动激活已有实例），以便不出现两个悬浮球（D38 per-session 互斥）
48. 作为用户，我想在**崩溃/重启后**看到上次任务标记为「中断」而非自动重跑，以便有副作用的任务不会被重复执行（§6）
49. 作为用户，我想让**更新不覆盖正在运行的 exe**（staging + updater + N-1 回滚），以便升级不翻车（D41(b)）
50. 作为用户，我想让**卸载时明确询问是否删除模型与数据**，以便不留几个 G 残留也不静默删我数据（D41(c)/§14.8）
51. 作为用户，我想在**省电模式下自动收缩**（关 KWS 常驻、缩短 Warm 窗口），以便笔记本续航不受影响（D42#6）

### G. 开发与交付（actor：用户本人 = 开发者；开发方 = AI Agent）

52. 作为开发者，我想**干净环境一键构建**出可运行 exe（流程冻结进 `docs/BUILD.md`），以便 AI agent 不在构建链上无限试错（§14.9，S0）
53. 作为开发者，我想让**构建工具链、前端构建、测试依赖全部容器化**，以便任何机器/CI 上结果一致（SPEC-11）
54. 作为开发者，我想让**开发环境与真实数据隔离**（独立数据目录/单实例锁/mock LLM），以便调试不污染自用配置与记忆（SPEC-03 §5）
55. 作为开发者，我想让语音链路用 **wav 注入测试**而非真麦克风，以便全链路可自动化（C8 测试地基）
56. 作为开发者，我想让 LLM 用**录制的 SSE 黄金流回放**测试，以便离线验证 Agent 循环全部行为（C5/C6）
57. 作为开发者，我想让**SLO 采样进 CI 做门禁且禁止放宽**，以便「轻量级」始终可测量（D32/D22 模式⑥）
58. 作为验收者，我想对每切片跑**对抗验收**（stub 扫描/契约偏离/DEFERRED 双向核对），以便「假装完成」无所遁形（D22）
59. 作为插件作者，我想照文档写出 **Tier1 清单插件与 Tier2 JS 插件各一**并通过契约测试，以便生态可持续（S8，DEFERRED）
60. 作为用户，我希望所有 UI **零 emoji、内联 SVG 图标、简约但高级**，以便产品有脸面（用户硬要求，§17）

## 5. 范围边界（Out of Scope，均为 PLAN 定案，不得「补回」）

- **REJECTED**：Coding/IDE 能力（草案 1.1）· 多 Agent 协作（草案 6.6）· 意图分类四级流水线（D11）·
  周期性调度器/cron（D12，一次性 `reminder` 为窄例外）· `fs.delete` 默认注册（D34，须 TOML 开启）·
  邮件/日历/IM **核心内置**（§15 第 10 项定案：插件路径已采纳，D46）
- **RESERVED（只留接口位，无实现计划）**：MCP client（D13）· Linux 支持（D7）· embedding 语义记忆（D20）·
  Codex guardian 双轴评分（D31）· 跨会话持久授权档（D45）· 精确 taint tracking（16.9#1）
- **DEFERRED（开源前不做，登记于 SPEC-12 §5）**：macOS · 代码签名/包管理器分发 · 插件 SDK/registry ·
  i18n（注意：语音链路是中文模型，非中文用户不是换 locale 就能用，D23 修正）· 无障碍 · AEC/barge-in ·
  快捷键路径下的语音否决（B1，依赖 AEC）· 剪贴板历史 · `doc.read` 的 xlsx/OCR · `system.eject`
- 平台：Windows 一等（自用期唯一目标平台）；macOS 二等（S8）；Linux 不承诺（D7/D23）

## 6. 术语表

| 术语 | 定义 |
|---|---|
| 悬浮球 / Ball | 常驻的 Win32 分层窗口自绘交互入口（非托盘图标，D2） |
| 态 / BallState | 20 态状态机（C12/D43），见 SPEC-08 §3 |
| `Warm` / `Conversation` | 会话保活两态（B4/C31）：模型热麦克风关 / 显式开麦多轮 |
| 会话（Session） | 唤起 → 显式结束或 90s 空闲；持有模型引用计数与授权（C31） |
| L0/L1/L2 | 风险级：只读直通 / 可逆写·执行前阻止窗口 / 不可逆·强确认（D4） |
| host bridge | 所有工具能力（内置/插件）的唯一执行收口点，权限校验在此（D3） |
| Tier1 / Tier2 | 声明式清单插件（含 D46 command 型）/ goja JS 插件（默认关闭）（D3/D19/F5） |
| taint / 污染 | C25 对工具输出打的敏感来源标记，出网前做 ≥8 字符片段匹配 |
| PathResolver | C26 唯一路径规范化入口（junction/8.3/UNC/`\\?\` 全防） |
| `artifacts\` | 宿主内部工件目录（长结果落盘、工具长输出 spill），500MB 配额，不经门控（D34 注②） |
| A 档 / B 档黑名单 | 绝对禁止不可覆盖 / 默认拒绝可单文件豁免（F1） |
| SLO 口径 | **进程树私有内存**（C30 Job Object `TreePrivateBytes()`），非单进程 RSS（D32） |
| X / Y 路径 | D25 语音拓扑二选一：Y=单进程延迟初始化 / X=语音子进程 stdio pipe；S0 spike 判定 |
| 对抗验收 | 与实现 agent 独立的第二 agent，专找 stub/契约偏离/SLO 放宽（D22） |
| WISP_ENV | 【SPEC】环境模型：dev/test/prod，隔离数据目录与依赖端点（SPEC-03 §5） |
