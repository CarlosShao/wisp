# 悬浮球热键（默认值与可配置备选）

> 本文件是**非冻结**说明文档：默认值与语义以代码为准（`internal/ball/hotkey_windows.go`），
> 契约层（`docs/PLAN.md`、`docs/specs/SPEC-03 §4`）不在此文件里改动。
> 建它的唯一理由是票 64 的 `:48` 框：**默认唤起键要写进文档**——
> 在那之前 `Ctrl+Alt+Q` 与 `Ctrl+Alt+Space` 只活在代码注释里，用户侧文档一个字都没有。

## 默认四个键

| 用途 | 默认绑定 | 说明 |
|---|---|---|
| 唤起（summon） | **`Ctrl+Alt+Q`** | 单击球之外的主要唤起方式 |
| 静音（mute） | `Ctrl+Alt+M` | 切 `Muted` 态 |
| 取消（cancel） | `Esc` | **仅在 `Confirming` 期间临时接管**（B1 语义），不是全局 Esc |
| 面板（panel） | `Ctrl+Alt+P` | 打开/收起面板 |

代码位置：`DefaultHotkeys()`（`internal/ball/hotkey_windows.go:61-63`）。

## 为什么默认不是 `Ctrl+Alt+W`（历史，别改回去）

`W` 是**旧默认**。owner 裁定 **R10（2026-09-20）**把它换成 `Q`，依据不是偏好而是实测：
在 owner 机器上扫了 **84 个候选组合**，`Ctrl+Alt+W` 是**唯一已被第三方占用**的那个
⇒ 在那台机器上它**永远注册不上**。（注册被占用的表现与语义见下节。）

## 可配置备选：`Ctrl+Alt+Space`

- 它是**受支持的替代唤起键**（代码常量 `AltSummonSpace`），在本机**注册得下来**，用户可自己在 `[hotkey]` 里填。
- 但它**故意不当默认**：多款中文输入法（搜狗 / 微信式的 shift-space、ctrl-space 上屏）**会抢在应用之前**
  吃掉 `Ctrl+Alt+Space`。⇒ 如果你把唤起键改成它，**换到某些输入法时可能失灵**，这不是 Wisp 的 bug。

## 改绑定会发生什么

`[hotkey]` 段属于**可热加载**配置：改完文件由轮询/推送路径重注册，**不需要重启**。
端到端行为有真机测试钉住（`TestLiveHotkeyRebindEndToEnd`）：改配置 → 新键按下真的唤起 →
**旧键按下不再唤起**，且一次编辑**只重绑一次**。

## 注册失败的两类语义（用户会看到不同的话）

| 情况 | 状态 | 用户可见提示 |
|---|---|---|
| 组合已被系统占用（别的程序先注册了） | `HotkeyTaken` | 明确说"这个键被占用"，并提示可改用备选 |
| 字符串无法解析成加速键 | `HotkeyUnparsable` | 明确说"格式不对，未尝试注册" |
| 配置里留空 = 该功能不绑键 | `HotkeyDisabled` | 说"未设置，已跳过" |
| 尝试了，但 Win32 因**其它**原因拒绝 | `HotkeyError` | 带原始错误，不折叠成"未知失败" |
| 正常注册成功 | `HotkeyLive` | — |

⇒ 一共**五态**（`internal/ball/hotkey_windows.go:225-236`），"被占用"与"未尝试"是**两类不同的失败**，
这就是为什么用户看到的提示不是一行 `Warn`。

⇒ 一个键失败**不会**连累其余三个（`registerAllWith` 逐条注册、逐条带状态），
且**没有任何失败是静默的**：每条都带可显示的状态与错误。
