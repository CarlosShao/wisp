## 1. 怎么填（三步）

1. 跑一次跑本（约 3 分钟，见 `real-machine-once.md`），记下它打印的 run 目录，例如
   `realonce`（或 `realonce-001`）。
2. 打开 `<run>\summary.md`：每行有 `id`（就是下表第一列的格号）、`status`、`value`、`source`。
   把 `value` 与 `source` **照抄**进下表；`status` 照抄（`READ` / `ABSENT` / 带 `-DISAGREES` 的记号）。
3. 抄完逐行核**判据列**：数字落在界内就写"符合"，落在界外就写"不符合：差多少"。
   **界是从码里算出来的**（见 §3），不是凭感觉。

一次会话对应一发 run；**换 run 就是换一列**（在表头补一列 `run=…`），旧列不删。

**⚠ 填表时会撞到的两件事（2026-11-14 自测里都出现过）**

1. **安静窗的 `mean` 低不代表 `max` 也低。** 自测里安静窗 `mean=0.001431` 而 `max=0.082235`
   —— 一声瞬时响动（碰键/门响）就过 `0.06`。判决看 `mean` 与 `449-d` 的**连续帧数**；
   遇到尖峰要在备注里具名"某一帧瞬时噪声"，⛔ 不许把它抹平，也⛔ 不许因此说尺坏了。
2. **今天这台机器可能根本没有直流底噪**（自测 `dc_mean ≈ -0.1 counts`，`dc_max_abs ≈ 193 counts`）。
   ⇒ 票面那枚 `0.368462`（≈`12073.76` counts）今天是**复现不出来**的；这时 `449 AC#8` 只能按
   "同一窗 `new ≤ old`（第 13 格）＋ `mean < 0.06`（第 12 格）"判，并把"0.368 不可复现"具名写进结论。
