## 4. 59-w 仪器工作与污染归因方法论核：**成立**

  自证）；strength 是离线在**原始采捕**上对重建 far 的相关——引擎状态物理上进不了这个量；

  纯回声而 ERLE 8.2）证明这对正交判据真能把「污染」与「引擎再收敛」分开。两类机制并存的归因
  成立。
