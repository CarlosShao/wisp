### 格 ② 并发路由 —— 10 路并发乱序回复正确配对

**②-a 现状**

回执的配对键是 **RPC 帧的 `id`（页面 `window._rpc` 的 seq）**，⛔ 不是页面信封里的 `requestId`。而这条管道**从票 299-r1 起是我们自己的代码**，不是库的：

```go

	...
	} else {
		c.Dispatch(func() {
```

页面侧槽由我们自己的 `Bind` 桩生成（同样是改名版，`panel_control_windows.go:897-913`）：

```js

	var promise = new Promise(function(resolve, reject) {     // :901
```
