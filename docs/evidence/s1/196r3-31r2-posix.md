## 2. 机制（可核，两处）

### 2.1 `filepath.ToSlash` 在 POSIX 上是恒等

`$(go env GOROOT)/src/internal/filepathlite/path.go:176`（go1.27.1 逐字）：

```go
func ToSlash(path string) string {
	if Separator == '/' {
		return path
	}
	return replaceStringByte(path, Separator, '/')
}
```

`internal/memory/open.go:226`（本腿**未改**）：

```go
d := "file:" + filepath.ToSlash(path) + "?_pragma=" + strings.Join(pragmas, "&_pragma=")
```

⇒ Windows 上 `C:\Users\x\wisp\wisp.db` → `C:/Users/x/wisp/wisp.db`（**这才是这枚用例真正量的转换**）；
POSIX 上 `ToSlash` 原样返回，`file:C:/...` 这个期望**不可达**。所以旧夹具把"Windows 的转换"当成"所有平台的转换"——红的是夹具，不是 `dsn()`。

### 2.2 第二枚：一个名字里带反斜杠的**另一个**文件

`internal/memory/open.go:40`：`dbFileName = "wisp.db"`（常量、不含 `'/'`），于是改前那行
`if strings.ContainsRune(dbFileName, '/')` **恒假** ⇒ POSIX 上 `dbPath` 是 `dir\wisp.db`。
`scalarAt` 用 `dsn(dbPath, true)` 去 `sql.Open` 它 —— modernc 当场**新建**一个空库（SQLite 的默认行为），
`SELECT count(*) FROM sqlite_master WHERE type='table' AND name='reminders'` 于是在空库上答 **0**。
真库（`dir/wisp.db`）里 5→6 那一步其实已经建好了 `reminders`（同一次运行里 `Open(dir)` 成功、`schema_version=6`），
所以这是"读错了文件"，不是"没建表"。

1. **Windows 字节不变**：`runtime.GOOS == "windows"` 分支返回的两个字面量与改前**逐字节相同**

   在 Windows 上就等于 `dir + "\\" + "wisp.db"`（`t.TempDir()` 不带尾分隔符）。Windows 侧改动前后都全包绿。
2. **非 Windows 用 `env:` 那条缝的形状**（`cmd/wisp/secret_fixture_180_test.go` 的先例）：夹具值经 `t.Setenv`
   发布到环境、再取回，用例吃的是**主机给的夹具**而不是第二份写死的副本；`t.Setenv` 事后自动还原。

   一个字节没动。
4. **不加 build tag、不改名 `_windows_test.go`、不 SKIP**：那会把用例移出分母（票 98 AC#2 / 票 180 的同一禁令）。
5. **未改 `dsn()` / `buildDSN()` / `migrationDSN()`**：本腿**零生产代码**，`internal/memory` 的冻结面一字未动。
