# 模型配置页 · 下一版（v2）设计要点

> 2026-10-14 编排者按机主当场反馈拟；**转交页面侧（机主的前端 agent）**。配套：`313-panel-ask.md`（接口规格＋当日的"措辞修正"节）。

## 0. 定性

- 现行页面＝"**先把线接通**"的联调最小面，**不是产品形态**：它是为了把"默认 stepfun＋在界面上配置"这条链路先跑通而做的最短路径。
- 机主反馈（大意）：**丑**；不像主流 harness 的设置页；**内容也不对**（内部开发语言直接上了屏；模型只能手填）。
- **根因一（我方）**：交接规格里带了内部词汇（"腿还没答""两半""建行的口"…），页面侧逐字上屏 ⇒ 已在 `313-panel-ask.md` 追加**替换表**（腿→"暂未读取"；两半→"供应商与模型"；枚举值→人话…）。
- **根因二（数据）**：仓内 stepfun **没有真实模型目录** ⇒ 选择器退化成手填 id（见 §3）。

## 1. 文案（先做，最快见效）

- **全站清理内部词**：腿／两半／建行的口／读面／回执／生效级别／枚举名（如 `no_ref_declared`）→ 全部换人话（对照表在 `313-panel-ask.md` 修正节）。
- 状态三态模板：**未读取**（灰）／**已配置**（绿）／**未配置**（黄）；错误态写"用户能做什么"，不写内部原因。
- 删掉"页面自言自语"式说明（"所以本步不需要动作""页面不另说"这一族）——标准设置页只留简洁标签。

## 2. 结构（主流 harness 风格）

- **供应商区**：列表行＝名称＋基址＋密钥状态点＋「测试连接」＋「编辑／删除」；列表尾「添加供应商」。
- **模型区**：默认聊天模型＝供应商下拉＋**模型下拉（带真实模型名）**；"手动输入"只作次要退路。
- **角色映射**：聊天／语音（ASR、TTS、实时）各选"供应商＋模型"；**成对校验放在保存时提示**（预先禁用按钮＝黑盒，别用）。
- **密钥**：密码框掩码；保存后只显示「已保存（引用名）」「更换」；**永不回显明文**；给「测试密钥」。
- **保存反馈**：一句"已保存，重启后生效／已立即生效"（把后端回执翻译成人话，不展示原始键路径）。
- **视觉**：与主面板设计语言一致（卡片／间距／圆角／状态色）；空态＝引导文案＋主按钮。

## 3. 数据缺口（"内容"要补的东西）

- **stepfun 真实模型目录**（文本模型＋audio3 语音）：仓内零名字。两条路：① 内置一份**真实**目录（模型名必须真实，⛔ 不许编造）；② 加"**从供应商拉取模型列表**"的能力（需 Go 侧新增只读口——**新方法名＝契约面**，先提编排者立票，⛔ 页面侧不得自造）。
- 语音链与实时头同理。

## 4. 接口（已就绪，v2 主要是页面端）

- **读**：`config.get` 回执里 `wisp-config-view:` 标记行后的 JSON（键表＝`313-panel-ask.md` §1）。
- **写**：白名单六枚（建供应商行／录密钥／文本角色成对／两条云链／实时两项）；成对与拒绝语义见 §3。
- 一句话：**后端的数据面与写入口已经通了；v2 ＝ 页面重设计 ＋ 真实模型目录。**
