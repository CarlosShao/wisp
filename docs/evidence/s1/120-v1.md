## 2. 三枚具名缺口的三态

### 缺口 1：`sealHandle` 那半 `SameFile` 零具名单元台件 —— 判 **缺世界**

产码 `winsec_other.go:269-274` 是 `sealHandle`（`PrivateFile`/`PrivateFileExclusive` 走的那条持 fd 入口）自带的
inline 复验；r2 的反控只去 `sameObjectPinned`（`pinPlacement`→按名入口）的牙。二者是两条不同腿。
**本腿实测**：在 `fixed` 快照上把 `sealHandle` 的两枚 inline 判据各改成 `false && …`（物理改写，clean sha `137442cd…`
→ 变异 `57e29c0b…` → 还原 `137442cd…`，`RESTORE MATCHES`，`.bak-120v1-sealhandle-control` 留底未删；仓内工作树全程未碰），
跑**整包** `go test -count=1 -v ./internal/winsec/` ⇒ **RUN=55 PASS=55 FAIL=0 SKIP=0，rc=0**。摘掉这一支的牙，
**零枚读数变色** ⇒ 今天没有任何用例造出"调用方 fd 已开在对象 A、名字随后被换成另一枚真对象 B、写之前 seal 才跑"
这一形（唯一使这半闸门说话的世界）。既有 `PrivateFile` 用例（113/118/119）都在 **open 之前**就把链接种在名字上，
`sealHandle` 在 `:257 applyDescriptor` 处已拒，**走不到** `:269`。
⇒ 判 **缺世界**（不是"不成立"：这半闸门读码形似正确；也不是"成立"：无任何证据它有牙）。
**去处**：落地腿须补一枚具名单元台件 + 反控**单独**去这一支的牙（r2 已把这条列进 §7 `next=2 补集`）。本腿⛔产码，不代它补。

### 缺口 2：形 1/2 去牙后仍 0 命中 —— 判 **成立**（是"判据射程限制"，非诚实缺陷）

r2 反控日志 `120-control-gate-neutered.log` 逐字：`sameObjectPinned` 去牙后，
shape1 `leaf-swap: hit-foreign=0 … --- PASS`、shape2 `ancestor-swap-absolute-link: hit-foreign=0 … --- PASS`、
**只有** shape3 `ancestor-swap-relative-sibling-link: hit-foreign=25 of-which-reported-nil=25 … --- FAIL`。
本腿独立看到同一机制：改后/去牙两跑的 other-shape 里都有绝对链接形自己的拒因
`openat blob.bin: path escapes from parent`——即 `os.Root` 对**绝对目标**链接在 open 处就拒，
加上 `platformVerifyPlacement` 预检腿，形 1/2 的 0 **不依赖**新闸门。
⇒ 判据**买到的**只有形 3：兄弟相对链接（`sub -> other`，无 `..`）是 Root 会跟、只有 `sameObjectPinned` 拦得住的形，
新闸门的牙仅此一处被证。形 1/2 仍在守 check-then-act 窗口（AC#1"修后=0"对三形都成立），
但**不能**把形 1/2 的绿算作"新闸门有效"的证据。这层落差 r2 已在仪器文件头缺陷 3、证据 §3 第 1 点与测试 `:239-241` 红句里具名，
**属如实披露的限制、非藏**。⇒ 成立；残余：若要形 1/2 也专门测闸门，须另造"Root 会跟"的相对形（已由形 3 代劳）。

### 缺口 3：`refused-at-act > 0` 今天只 `t.Logf` 不 `t.Errorf` —— 判 **成立**（建议⛔ 整体升硬，会 flaky/恒红）

读码：`posix_seal_window_120_other_test.go:239-241` 是**无条件** `t.Logf`，无 `t.Errorf`。
**本腿复跑的逐样本证据**（fixed 默认严格档，同一发 4 样本）：
```
shape=leaf-swap               per-sample refused-at-act = 2, 2, 3, 6
shape=ancestor-swap-absolute  per-sample refused-at-act = 1, 1, 0, 0   <-- 样本 3/4 为 0
shape=ancestor-swap-relative  per-sample refused-at-act = 4, 1, 6, 6
```
绝对目标形里，多数拒绝合法地来自**预检腿/stdlib**，pinned 闸门不必每样本都开火——我这一发已有 2/4 样本
`refused-at-act=0`。⇒ 若把"每形每发 refused-at-act>0"升成硬判据，**会 flaky、形 1/2 上近乎恒红**，
与本仓"不误红、不为变绿放宽"纪律相冲。
⇒ 判语：**保持为上报列，⛔ 整体升硬**。闸门的牙已由**去牙反控**（缺口 2）钉住——去 `sameObjectPinned` ⇒ 形 3 红、
且去牙后 `refused-at-act=0` 遍布所有形，正是"闸门没开火"的形状；这比逐样本 `refused-at-act>0` 硬阈更稳。
残余（归落地腿/编排者）：若坚持要"闸门确有开火"的默认硬信号，**只**对形 3 施加，且需接受其在小分母下的概率性。
