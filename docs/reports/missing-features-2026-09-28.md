# 别人有、我们没有 —— 功能清单（2026-09-28）

调研对象：本机 `D:\work\AI\open source` 下的四套开源 harness —— DeepSeek Harness（桌面版，Electron 窗口）、Step-Code（终端）、MiniMax Code（终端）、Pi（终端）。
每条后面标的是**几家真做出来了**（"真做"＝代码里接上了、不是只写在文档里）。最后一列是**我们今天的情况**。

看的时候只用记住一件事：**今天这产品唯一能跑通的用法，是在命令行里打一句 `wisp run "任务"`。** 界面上的球和面板代码都写了很多，但产品进程根本没把它们加载起来。

## 3. 让它有手（能干活的种类太少）

我们今天只有**跟文件有关的六件事**（读、列、写、改、移、丢回收站）。别人都几十种。缺的、而且**我们自己的方案里早就列过、只是还没做**的：

| 缺的能力 | 什么场景 | 别人 |
|---|---|---|
| 跑命令 | 装东西、跑测试 | 4/4 |
| 全局搜代码、按名字找文件 | 找一个用法 | 4/4 |
| 搜网页、抓网页正文 | 查最新资料 | 3/4 |
| 发系统通知（尤其"要审批了"叫我） | 跑长任务时走开 | 3/4 |
| 读/写剪贴板 | 粘贴、口述成文 | 2/4 |

| 在浏览器里点、填、截图 | 网页流程代跑 | 2/4 真做 |
| 开本地程序、列窗口、切窗口 | "帮我打开那个东西" | 3/4 |
| 读电量/网络/音量/焦点窗口 | 场景感知 | 2/4 |

## 12. 我们本来就有、别人没有的（别丢）

资源占用硬预算与实测、每步的污染来源追踪（防"网页里的假指令"被当成本机说的话）、密钥走系统加密存储、判定分层与不可覆盖的黑名单、二十种状态各有视觉、球本体。**这几条四家都做不过我们**，其中"来源追踪"只有一家做了半个（他们靠转义字符）。

## 13. 语音（四家都没有，是我们的差异）

采集有代码但**没有任何地方调用它**，识别和播报**整个包是空的**，唤醒词没有。也就是说"说话→它听懂→干活→念给你听"今天**一环都不通**。这块不属于"别人有我们没有"，属于"我们答应过自己但还没做"。
