# 别人有、我们没有 —— 功能清单 第二版（2026-09-28，含对我自己第一版的更正）

调研范围已扩到**五家**：DeepSeek Harness（桌面窗口）、OpenChamber（服务端＋桌面/网页/VS Code/手机四壳）、Step-Code、MiniMax Code、Pi。
看这份之前先记住今天的真实情况：**这产品唯一跑得通的用法是命令行 `wisp run "任务"`**；球和面板代码很厚，但产品进程没加载它们；**到点该问用户的审批没人能答**。

---

## 零、先更正我上一版写错的（那版我已经发给你了，所以更正摆第一页）

1. **"语音四家都没有"——错了。** OpenChamber 有听写（麦克风钮、波形、4 枚可下载可删的本地识别模型）也有播报（浏览器/系统/服务器/本地四路，逐条消息"念这条"）。我已复算：输入框文件里"听写"出现 **23 次**、`components/dictation/` 两枚件、`hooks/` 里四枚播报钩子都在。
   ⇒ 差异不在"有没有语音"，只在**"常驻＋随时接话＋说完就播"**。这条我不该报成优势。
2. **"自动更新 4/4"过头。** Step-Code 代码里逐字写着"这次安装不是独立二进制，没法自更新"（我复算：两处命中）；MiniMax 自己给这条打了折。⇒ 实数**装了安装包的两家能自更新**。
3. **"安装程序 4/4"也过头。** Pi 的安装脚本只给 macOS/Linux；Step-Code 的 Windows 安装是 beta 且官方建议用 WSL。⇒ **真做到"双击装完"只有两家**。
4. **"两家各写上千行命令解析"只能证一家**（MiniMax 那份解析文件 **436 行**，我数过）。DeepSeek 的守卫目录里**没有命令解析**（只有"重复调用提醒"和"超时策略"）——它走的是**另一条路：根本不让它碰本机**。**这一整类目我上一版完全没写**，见第三节。
5. **"长期记忆 1/4"分母错** ⇒ OpenChamber 也有一份（分"事实/偏好/外部指路"，还专门防"读不出来就当全忘了"）。按五家至少 **2/5**。
6. **"来源追踪只有一家做了半个"低估了** ⇒ OpenChamber 也用包裹标记；Step-Code 与 Pi 另有**"第一次进这个目录先问信不信"**这条不同路径。⇒ **"四家都做不过我们"那句我删了**，改成："逐来源追踪"仍是我们独有，但**"项目信任闸门"我们完全没做**。
7. **所有"3/4""2/4"的分母要重数为 5**，稀有度也变了：**"通知按事件分开关、你正在看就别吵"**原来是亮点，现在是桌面产品的及格线。
8. 另四处小口径：拖文件与终端看图那条挂在**终端能力探测**上（Windows 原生终端多半不支持，不能写 4/4）；"一键搬配置"里 MiniMax 和 Pi 搬的其实是**会话**不是配置；"崩了落盘＋预览会上传什么"实为 **2/5 不是 4/4**；"分栏 3/4"低估了差距（DeepSeek 是一整套**布局改动能撤销**的引擎）。

## 九、五家都没有、但我们做常驻桌面助手迟早撞上（这节是给我自己排未来票的）

1. **随时插嘴**：它正在念、我打断它——五家的语音都是按键开关的听写，没人处理"该不该接话"。
2. **跟系统勿扰联动**：Windows 专注模式/会议中/全屏游戏时**只留审批、别留闲聊**（现在只有"是否在后台"这一维）。
3. **麦克风硬件级静音**：一键闭麦并把球变灰，还要显示"麦克风被别人占着"。
4. **播报时自动压低音乐**（音频闪避）——五家都没做，常驻助手一开口就盖掉用户的会议。
5. **"没坏但也没消息"的报平安**：长跑任务超过 X 分钟既没进展也没提问，主动说一句"我还活着，卡在哪儿"。
6. **谁在跟我说话**：共用机器区分说话人、各套各的偏好。
7. **"今天它替我做了哪些决定"的日报界面**——五家都有历史，没人把"自动放行的每一次"汇成一份，这是常驻助手最容易失去信任的地方。
8. **一次误批之后的批量收回**："一直允许"存的规则只能一条条看，没有"昨天那条算我手滑，把它已经做的事退回去"。
9. **被系统打断后从哪儿续**：睡眠、锁屏、Windows 更新重启之后的会话与说到哪一句。
10. **色盲安全配色／不只靠颜色区分状态**——五家只保证对比度；**我们那 20 种球状态恰恰全靠颜色**，这条对我们是真实风险。

## 十、不建议抄（给形状级理由，不是拿门禁当理由）

- **隧道、远程实例、手机壳、VS Code 扩展、多路比稿与融合**：那是"一套服务端摊到多端"的产品形状才需要的；我们是**本机常驻单用户**，抄过来只会变重。
- **MCP/插件市场/扩展 SDK 整套**：五家只有两家真在用，其余市场是空的或只有两枚插件；我们先做**"能接一个外部工具"的最小闭环**，不做市场。
- **完整 Git 工作台**（分支图、rebase 续作、多 git 身份）：与语音助手用户重叠度低，票 186/187 只做"认出工作区＋切换"就够。
- **隔离容器（Docker 空间）**：OpenChamber 自己把它藏到首发之后（代码测试齐全，由一枚常量挡住不渲染）——**说明它自己也没验完**；我们先走 DeepSeek 那形（操作系统级权限标签），代价票 91 已量过。
