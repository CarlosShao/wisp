## 4. 铁律（不可协商，逐条都能在盘上核）

### 4.1 Git 与推送

- **腿只 commit，不 push**；推送只由编排者做。
- 推送**只推 `origin/dev`**（owner 授权＝台账 `A813`）；⛔ 裸推（会去 cnb）、⛔ `--force`。
- 推前必须验 fast-forward：`git rev-list --count HEAD..origin/dev` == 0；推后验**远程 tip 逐字等于本地 HEAD**（不要只 grep `dev -> dev`）。
- **`git add` 与 `git commit` 两处都带逐枚显式 pathspec**；⛔ `git add -A`／`git add .`／目录形／`git commit -F 正文 -- .`（这个形状曾把别人的 24 枚在飞路径吞进历史）。
- ⛔ `--amend`／`reset`／`rebase`／`stash`／`checkout .`／`clean`；⛔ 在仓库目录内建 worktree／checkout。
- `git mv` 改名必须**一笔带新旧两枚 pathspec**；改名后跑 `git ls-tree HEAD <目录> --name-only | grep <票号>- | wc -l`，`-done` 后缀是防重领唯一键，**只许命中 1 枚**。
- 撞 `.git/index.lock`：⛔ 删锁；等它自己散，再重试**同一笔**。
- 共享工作树里发现暂存区被别人的在飞文件污染：三步归位——①逐枚证"还在盘上"；②`git restore --staged -- .`（只退暂存、一字不动内容；⛔ 与禁掉的 reset/stash/checkout . 同形）；③只 add 自家＋commit 带 pathspec。⛔ 猜归属、⛔ 清空别人的 staged。
- 临时件**只建不删**（仓外台件、日志、探针都留着）；共享工作树里的未跟踪历史件不要清理。

### 4.4 证据与测量

- 凡读别人的字节，一律取**具名提交树**（`git show <rev>:<path>` / `git grep <pat> <rev> -- <path>` / `git archive <rev>`）；⛔ 读工作树里正在飞的字节。
- **⛔ 在共享工作树跑 `go test`／`go build`**（会与别人的腿抢编译面/污染读数）；这类"不可盘核的自报"不算凭据。门禁（`d22scan`／长度门／`gofumpt`／`go vet`）可以在工作树跑，因为它们是静态的。
- 四数必须逐枚点名：`^=== RUN`（含子测试）／`^--- PASS`（只顶层）／`^--- FAIL`／`^--- SKIP`。⛔ 混用，⛔ 相减（RUN−PASS＝子测试数，不是失败数）。
- `go test` 一律 `-count=1 -timeout 30m`（或更长）；颜色必须**同一台面**成对（改前⇄改后），红名册**逐名作差**，⛔ 只报枚数。
- 跑 `./cmd/wisp` 必须补 PATH：`PATH="$PWD/third_party/sherpa-onnx:$PWD/build:$PATH"`；否则 `0xc0000135`＋零枚 `--- FAIL`＝那包根本没跑，不是红。
- `gofumpt` 指到 `.md` 会 rc=2 `illegal character U+0023`＝仪器用错，⛔ 当红。
- 突变台件：只在**仓外导出树**的物理字节上改；⛔ `-overlay`、⛔ 改共享工作树的跟踪文件。内容锚（不是行号锚）；每发前后算文件哈希；`finally` 还原并验证哈希；pristine 正控必须绿；两发串行，残留窗口里的两发红句彼此不独立。
- 判据的"牙"：**把判据换成反形后仍然全绿＝它对这件事不敏感**，不许当凭据。还要问"两种取值不同所需的那个世界，夹具里有没有造出来"（缺世界）。
- 级联红只能靠**成对摘除**读数；⛔ 把"红 9 枚"读成"更强"。
- 红句必须带"哪一行/哪枚用例红"；`walk: file not found`／`build failed`／`no tests to run`＝台面故障，⛔ 计入判据。

## 9. 仪器与陷阱库（这些是拿血换的，照做能省你一天）

### 9.1 收件与尺

1. **前缀尺先采样**：用 `git log --grep='^票 NN 落地腿'` 之前，先 `git log --all --format='%s' | grep 'NN-r' | head -3` 看真实主题形状。同一天我猜错三次（真形是 `票 334 腿 334-r1`、`票 334 产码腿 334-r1`、`328-r1 `）。
2. **越格指控⛔ 用子串尺**：`--grep='334-r1·'` 会把我自己的提交扫进来，造出"票 332 文件越面"的假指控。用严格前缀＋逐条 `git show --stat` 人工核。
3. **行尾形状尺**：`perl -ne '!/\r$/ && /\n$/'` **恒真**（以 `\n` 结尾的行永不以 `\r` 结尾），我因此报过"45 行全中"的假读数；正确是 `!/\r\n$/`。`awk index($0,"\r")==0` 在本机 msys 同样坏。**落笔前先拿已知分母打一发**（知道总数和例外数，凡读回总数就是尺坏）。
4. **`grep -c` 命中 0 时 rc=1**，会截断 `&&` 链；用 `N=$(… || true)`。
5. **两把尺矛盾时，先假定新那把坏**；保留坏件留档，⛔ 删。
6. **0 字节＝没交**：找同名带 `rc=`／`.log` 的同伴件；入库前 `git ls-files <写面> | wc -l` 对拉腿报的枚数。
7. **`git mv` 后验唯一性**：`git ls-tree HEAD <目录> --name-only | grep <票号>- | wc -l` 只许 1。
8. **通知／中途报告／注释里的测试名，全是待验断言**；⛔ 凭它们翻框。

### 9.2 突变台件

10. 导出树现行配方：**八件套** `go.mod go.sum internal cmd tools scripts frontend models` ＋仓根 `docs/`（有些测试读 `PLAN.md`）＋手工三件 `build/*.dll`、`third_party/sherpa-onnx/*.dll`、`frontend/dist`；树放 `D:` 卷（8.3 短名），先 `mkdir -p` `GOTMPDIR`；量之前 `find <树> -name '*.go' | wc -l` 证非空。少一件会造**假红**（`walk …: cannot find the file specified` 长得像牙响了）。

### 9.3 环境

## 10. 标准操作配方

### 10.1 翻一个 AC 框（凭非实现者判语）

```bash
# 1) 先数，带前后对照
f=.scratch/wisp/issues/NN-slug.md
grep -c '^[[:space:]]*- \[ \]' "$f"; grep -c '^[[:space:]]*- \[x\]' "$f"
# 2) 只翻判语点名的行（例：33,34,36-39）
sed -i '33,34s/^- \[ \]/- [x]/; 36,39s/^- \[ \]/- [x]/' "$f"
# 3) 再数＋看内存改了几行
grep -c '^[[:space:]]*- \[ \]' "$f"; grep -c '^[[:space:]]*- \[x\]' "$f"
git diff --numstat -- "$f"
```

- 只翻**非实现者判语成立**的格；"半成立/部分成立"按票面判据决定翻不翻，拿不准就留空并在票尾具名残余。
- 票尾追加**一条只追加 bullet**（写判语件路径、判语、残余、锚），⛔ 改判据原文、⛔ 改 `Status:`（除非你就是在改 Status，按票面规矩来）。

### 10.2 结案改名

```bash
old=.scratch/wisp/issues/NN-slug.md
new=.scratch/wisp/issues/NN-slug-done.md
git mv "$old" "$new"
git add "$old" "$new"          # 两枚 pathspec 都要
git commit -F <msgfile> -- "$old" "$new"
git ls-tree HEAD .scratch/wisp/issues/ --name-only | grep '^NN-' | wc -l   # 必须是 1
```

- `-done` 是防重领唯一键；HEAD 同时挂两个名＝改名失败。

### 10.3 收一条腿（三把尺）

```bash
# ① 提交真在（逐枚）
git log -1 --format='%H %s' <sha>

# ② 件真在（非 0 字节）
wc -c docs/evidence/s1/<件>.md
git ls-files <腿写面> | wc -l        # 对拉腿报的枚数

# ③ 自己复跑决定性的那一发（不是抄腿的读数）
#    例：成对突变 / 指定用例 / 门禁 rc
```

- 腿的"完成通知"只当线索；必须自己取数。
- 腿死后的遗产：按枚代提、一字不改，标 `〔未验证半成品·AC 框未翻〕`；另派新腿接续。

### 10.4 台账 + 停车点 + 提交

```bash
# 1) 写正文到文件（中文含反引号/美元符时⛔ 直接内联双引号）
#    用 Write 工具写 .scratch/.../A1022.txt，再 cat >> 台账
cat .scratch/wisp/probes/orch/20261017/txt/A1022.txt >> docs/reports/pending-and-issues.md
cat .scratch/wisp/probes/orch/20261017/txt/HANDOVER-40eg.md >> docs/reports/HANDOVER.md

# 2) 两处都带逐枚 pathspec
git add docs/reports/pending-and-issues.md docs/reports/HANDOVER.md \
        .scratch/wisp/probes/orch/20261017/txt/A1022.txt \
        .scratch/wisp/probes/orch/20261017/txt/HANDOVER-40eg.md \
        .scratch/wisp/probes/orch/20261017/txt/40eg-msg.txt
git commit -F .scratch/wisp/probes/orch/20261017/txt/40eg-msg.txt -- \
        docs/reports/pending-and-issues.md docs/reports/HANDOVER.md \
        .scratch/wisp/probes/orch/20261017/txt/A1022.txt \
        .scratch/wisp/probes/orch/20261017/txt/HANDOVER-40eg.md \
        .scratch/wisp/probes/orch/20261017/txt/40eg-msg.txt
```

- 提交前 `git status --porcelain -- <每枚路径>` 确认没有别人的在飞文件混进来。
- 提交后回读：`git log -1`＋`git show --stat --oneline HEAD`。
- 停车点每节写清：①本笔做了什么；②残余（具名、归谁）；③编队（在飞/按住/CPU）；④下一步顺序；⑤门禁；⑥推送状态（含未推数与 HEAD）。

### 10.5 派腿（存档先于发送）

1. 在 `.scratch/wisp/probes/orch/YYYYMMDD/txt/` 写 `<腿名>-head.txt`（目标/锚/写面/禁区）、`-common.txt`（公共铁律）、`-specific.txt`（本腿判据）、`-dispatch.txt`（拼起来的完整派单）；

4. 只有 `-send.txt` 里真有 agentId／启动动作，才算"在飞"。

## 12. 术语表（新 harness 先背这些）

- **票**：`.scratch/wisp/issues/NN-*.md`；一个可交付单元。
- **框/格**：票里的 `- [ ] AC#n`；翻成 `- [x]` 叫"翻框/勾格"。
- **`-done`**：结案票的后缀，防重领唯一键；**零残余证明**。
- **腿**：子代理。命名：`NN-r<N>` 实现腿、`NN-v<N>` 验收/终裁腿、`NN-a<N>`/`NN-c<N>` 普查腿。
- **写面**：这条腿允许改的路径清单；越面＝违规。
- **在飞**：已经真的启动（有 agentId/启动动作）；只有派单存档＝待派。
- **按住**：有意不派，等某个前提（CPU、写面、前置票）。
- **收件**：按盘上三把尺验收腿的交件。
- **代提/代笔**：腿死了，编排者把盘上遗产按枚入库（不验证内容、只保字节）；必须标〔未验证半成品〕。
- **判语**：验收腿对每格给的"成立/不成立/不适用/不可判"。
- **牙**：判据真的能咬红；"没牙/恒真/装饰断言"＝不敏感的判据。
- **正控**：已知该红/该绿的一发，用来证明仪器和台面没坏。
- **去牙**：故意把被测守卫摘掉，验证判据会红。
- **反形**：把判据换成相反形状，验证它仍能区分。
- **假绿**：判据绿了，但它防的事根本没被覆盖（例如拒绝来自另一道门）。
- **缺世界**：夹具里不存在"两种取值不同"所需的输入。
- **台面/导出树**：仓外用 `git archive` 取出的树，用于跑测试/突变，避免污染共享工作树。
- **锚**：判据所依据的具名提交/文件哈希；⛔ 用 `HEAD~n` 或会腐烂的行号。
- **账**：台账里的 `A##` 条目。
- **停车点**：`HANDOVER.md` §4 的最新一节，告诉下一个人从哪儿接。
- **机主**：owner（swq/CarlosShao）。
