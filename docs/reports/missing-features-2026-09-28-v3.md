## 一、先更正我上一版写错的、和说轻了的

上一版我已经发给你了，所以更正必须摆第一页，不能塞在后面等你发现。

1. **"Go 侧一枚子代理实体都没有"——这句过期了，今晚三层全进仓了。**
   我原来那句是有读数的（搜"子代理"在非测试代码里 0 命中），但那是 18:1x 的数。今晚：
   - **实体那一层**：一个 452 行的文件真的存在了——模型可以使出"派一枚子代理"这枚工具，每枚子代理拿到自己的编号、进那张多任务名册（就是"现在谁在跑"那张表），状态只用我们那张**定好的状态名册**里的名字，不许新造第二套；一次最多 4 枚；只许往外派一层；而且子代理自己能用的工具清单里，"再派一枚子代理"被**删掉了**（防它自己繁殖）。
   - **流那一层**：每枚子代理一行自己的文本，不再和别人合并。⚠ 这里我原来那条判据是错的，得更正：旧做法是"名册装到 32 条就**把两条并成一条**"，而两条子代理的输出并成一行 = **界面在说谎**。现在改成"显式标出被截断、并说少了多少"。
   - **载体那一层**：今晚四个提交入库，名册和每枚子代理的流**真的进了每次刷给界面看的那一包内容**。真字节读数：`rows=2 poolCap=4 runStatus=Thinking afterStatus=Settling bytes=2789`，溢出那一发 `rows=34 streams=34 truncated=true dropped=[]`。
   ⇒ 对你的实际影响：**这一格不再是"要不要做"，而是"界面画不画"**。

2. **"快捷键：有热键但不能改"——这句两处都不准，属于我上一版把你带偏的那类。**
   事实是：配置里**有 4 枚可改的键**（召唤我／静音／取消／开面板），而且改完会**自动重新注册**，不用重启；甚至有一份"当前哪几枚键注册成功了"的可读清单。我们还有一件**比 DeepSeek 更早踩到**的东西：Win32 全局层的**输入法抢占实测**——搜狗/微信那种"空格提交""Ctrl+空格提交"会抢走 `Ctrl+Alt+Space`，而且**在你这台机器上扫过 84 枚候选组合，只有 1 枚被第三方软件占了**。DeepSeek 那边只有网页层的输入法保护，没有这一层实测。
   真正没有的是**三件配套**：① 一张"能绑哪些命令"的目录窗；② 录键界面＋撞键拒绝＋"恢复全部默认"；③ **产品那条路上没装**——那条"改了自动重注册"的桥，今天唯一的真调用者是一枚调试小工具，产品入口 0 处。
   ⇒ 这一条属于第三种"没有"：**做了，但没人接上**。不是"完全没有"。

3. **界面那一跳，今晚要补的是两枚条目不是一枚。**
   红字逐字是：Go 发出 `[instructions tasks]`，而界面那侧的声明里没有这两样。`instructions`（项目说明清单）来自另一枚活，`tasks`（子代理名册）是今晚这枚带来的。我原来只报了后者，把你少报了一枚。
   ⚠ 更要紧的是**形状今晚换过一次**：项目说明那枚本来是"一个列表"，改成**带状态的一节**，状态有五种——真加载了／开着但目录里没文件／你关掉了／路径被改写所以拒读／这一轮还没跑到。换的原因是旧的形状下"功能没开"和"目录里没文件"在界面上**看起来一模一样**，界面就没法说实话。这正是我在下面第二节要讲的那类病。

4. **上一版我把语音的差异写成"我们多了'说完就播'"——那半句说过头了。**
   OpenChamber 的播报是**手动按钮**（逐条消息"念这条"），我没找到"它说完就自动播"的痕迹；而且他们**没有按住说话**，入口是点一下开始、再点一下结束。
   ⇒ 所以"说完自动播""按住说话"这两条**不是人家的及格线，是五家都没做过**。别把它们当成必须补的洞——它们是第一节里唯一一条"我们本来打算领先、结果发现前面没人"的东西。

5. **"听写这条人家有、我们没有"——归错类了，这条要换个说法。**
   他们的识别引擎是 sherpa-onnx，而**我们自己规划用的就是同一家引擎**（这在我们自己的设计文件里逐字写着）。所以这不是"人家有我们没有"，是**同一条路上，人家已经把实测账交完了**，而这些数是我们迟早要自己撞出来一遍的：
   - 那段模型算得随长度**平方**涨：60 秒 = 2.1 秒耗时/+90MB，180 秒 = 9.3 秒/+490MB，300 秒 = 21.3 秒/+1.5GB。**所以他们 60 秒一遇静音就交一段，90 秒硬顶。**
   - **振幅峰值低于 300 的静音段直接丢掉**，为的是不让识别器在静音里"幻听"出字来。
   - 只确认**连续的**序号，没被确认的那段自己重传。
   - 转写稿**绑定"开始录音那一刻的那份草稿"**——你在等回字的窗口里切走了会话，文字仍塞回原草稿，不会串台。
   ⇒ 我上一版把它归成"功能差"，归错了。这一条的实际价值是**省钱省时间**，不是补功能。

6. **"从快捷方式启动时补全 PATH：半个"——说轻了，等于没说。**
   他们把这道题写成了一套**可直接照抄的四级回退算法**：先用 PowerShell 取一份当前环境清单 → 再退到另一个 PowerShell → 再退到系统目录里的全路径 → 最后退到用 `cmd` 问一遍；解析时用**不可打印字符当分隔符**（防路径里有空格把结果切碎）；隐藏窗口；10 秒超时；还是找不到，就再问一句"你到底装在哪儿"。
   ⇒ 我们缺的不是"半个功能"，是**整套算法都没有**。而这正是"双击打开的桌面 App 说找不到 npm，但你打开终端就有"那一类幽灵 bug 的唯一根。

7. **上一版"不建议抄"那一节里，我把"手机壳／VS Code 扩展"整个划掉了——要收窄。**
   壳本身确实不该抄（我们是本机单用户）。但今晚读穿后发现壳里有**四条跟"哪个端"完全无关**的规则，值得抄：
   - ① **别用"问客户端你还在不在"当"要不要吵你"的门**。他们踩过这个坑，注释里逐字写着那道门在网页容器里有竞态，于是**主动放弃**它，改成"永远发、让操作系统自己压前台"。
   - ② **断线重连之后先对齐权威态**：唯一真相是"此刻在跑的那份清单"，**凡不在册的一律算没在跑——包括我自己断之前以为在跑的**。
   - ③ **冷启动时那份"要点开哪一条"的意图先存住不丢**，界面起来了再放出来。
   - ④ **子代理还在跑的时候，父任务"我做完了"那条通知不许发**（查不了才照发，是有度的兜底，不是不设防）。
   ⇒ 这四条不是"多端才需要"，是**任何"人不在屏幕前"的产品都需要**。

8. **"五家都没人把自动放行的每一次汇成一份日报"——这句维持，但欠一句更准的话。**
   我特意去查了那枚名字最容易误会的模块，结论是**它不是日报**，是"用户点提交反馈时，把一棵会话目录里的文件打包成一份清单"。⚠ 仓里确实有一枚叫"每日摘要"的设置，但它写的是**记忆文件**、**默认关**，而且被它引用的那个实现文件**在这份公开副本里根本不存在**——所以以后谁跟你说"MiniMax 有日报"，那是把"整理记忆"读成了"汇报决定"。

## 二、"没有"分三种，这一版每条都标了是哪一种

今天我在快捷键那一条上把你坑了一次（我写"完全没有"，其实配置里有 4 枚可改的键）。所以这一版每种"没有"都分开写，因为**下一步动作完全不同**：

| 标 | 意思 | 下一步 | 今天的例子 |
|---|---|---|---|
| 〔根本没做〕 | 那一层东西在仓里不存在 | 要新建一整块 | 对话消息那张表根本没有；agent 反问人那一整条 0 命中 |
| 〔做了但没人接上〕 | 代码在、能跑、但产品那条路上没人调用它 | **补一行装配**，最便宜 | 快捷键"改了自动重注册"那条桥，唯一的调用者是一枚调试小工具；球和面板整包代码在产品进程里没被装上 |
| 〔做了但只在测试或命令行里能跑〕 | 只有测试、或者只有你手动敲命令才够得着 | 要把"人点一下"那一路接通 | 网页到 Go 之间那四道门，只接通了一道，而调用方是**人拿命令行**，不是用户点界面 |

⚠ 还有一类**不是"没有"**，是"取向不同"（比如"要不要允许未知工具默认放行"、"定时交给系统而不是自己做调度器"、"我们撞线必停、他们只提醒不停"）。这一类我只在你问的时候标出来，不混进缺功能里。

## 三、子代理：今天做到哪、还差哪、你要转给界面那支的原话

这是你今天盯得最紧的一块。你的原话逐字是：「**子代理必须看到状态，而且点击某个子代理，能看到它们各自的流式工作页面，能明白吗？这是主流 harness 必做的，不要偷懒**」，以及后来那句「**必须特么做完整功能，明白吗？**」。下面按这三段要求逐段对。

### 3.1 今天已经做到哪一步（只说盘上有的）

**① 名册：有了。**
"现在有哪几枚在跑、谁是谁的孩子、它此刻算哪种状态"这张表是真的存在了，有 15 个动作（记录／查一行／数几枚／列某人的所有后代／发布一枚子代理／占用与释放并发名额／查谁在飞／查谁在跑／挂上取消／摘下取消／取消）。
一条名册行现在带这些内容（这就是界面能画的东西）：**编号、给它起的名字、它是根还是子、父亲的编号、当前状态、这状态知不知道、不知道的话为什么不知道、它自己那一行的流编号、是不是卡在等批准、它的流有没有被截断、少了多少、有没有整段被丢**。
状态**只准**用那张定好的状态名册里的名字（今晚真字节读数里是 `Thinking` → `Settling`），不许新造第二套词——新造词会让"同一件事在两个界面上长得不一样"。
⚠ **诚实数**：并发名额今天是 **4**，不是 8。4 这个数字是**从"同时能执行几枚工具"那枚写死的天花板借来的**，而且我原来那条判据量的是一条绕开天花板的路——所以 8 这件事**不是改个数字**，要动的是"整个进程同时执行工具的上限"，那是要你一句话的级别。**已经立了一枚票把界线写死，我按 4 先落地，没等你这句话。**

**② 每枚自己的流：有了，而且"被截断"现在会说实话。**
每枚子代理一行自己的文本，键形状具名（`subagent:<它的编号>`）。我原来那条"装到 32 条就把两条并成一条"的做法被**推翻**了——两个子代理的输出并成一行等于界面在说谎。现在：
- 溢出**显式标**"已截断"，并给出"少了多少"；
- 有一枚**结构性判据**：造 N+1 枚子代理，**没有任何一条会被并进别人的**；
- 有一枚常驻判据把"那一页必须标出结束"钉住在工具层，不只是测试层；
- 今晚的溢出读数：`rows=34 streams=34 truncated=true elided=0 dropped=[]`（34 条流各占一行，截断旗亮，但没有整段被丢）。
- ⚠ 有一处**只能到"面板层钉住、生产层没量到"**：真装配上"少了 N 段"和"丢了谁"不可达（测试用的假大脑有 400 字节上限）。这一处我登记了，没假装量过。

**③ 载体：今晚进仓了。**
名册和每枚子代理的流**真的进了每次刷给界面看的那一包内容**，而且是走**生产路径**的判据（不是包内自测）：**拔掉那根泵，产品那条路必须判红**。今晚四发单点变异里就有这一发，读数是"产品判据红、包内判据全绿＝那把尺是瞎的"——所以他们把包内那把也补活了。
另外今晚还钉住了三件我很在意的：
- **流编号只有一个铸造点**（不许两处各写一份同样的拼法；这条是我上一轮发现的"两个包各定义了一遍"，现在有了真钉）；
- **名册行喂给哪一条包，那一条包就得是它的**；
- **名册之外的状态名根本到不了线上**。

**④ 三条安全形状，已经在实体层里：**
- 子代理的工具清单里**删掉了"再派子代理"**（防它自己繁殖）；
- 子代理**不许自带"允许"这个出口**（它遇到最严那一档只能把问题**上抛**给同一张面板队列，或者被父亲取消）；
- 它读回来的文件内容照样走那套"来源盖戳"，不许绕过。

### 3.2 还差哪一步（每条标是哪一种"没有"）

**差一：名册一行给不出"它花了多少钱、跑了多久"。**〔根本没做〕
- 别人怎么做：名册每一行右侧有两列——**这枚子代理累计烧了多少**（四个互不重叠的桶相加：没命中缓存的输入、输出、读缓存、写缓存），**它这轮已经干了多久**。
- 我们现在是什么样：一条名册行**根本没有花费和计时这两个位置**，六个字段里只有文本、产物路径、状态、父亲、名字、种类。
- 不做的后果：它派出 4 枚子代理，一小时后你问"哪枚最贵、哪枚卡了 20 分钟"——**这两个数今天不存在**，而且不是界面没画，是源头没有。你想看的"它在跑"就成了唯一能知道的信息。

**差二：那本"每行带序号、可以回放"的会话账本，没有。**〔根本没做〕
- 别人怎么做：会话的每一步都落成带序号的持久记录，一共 **59 种**不同种类的行；界面上那一页只是这份账的一种看法。
- 我们现在是什么样：那个包目录下**只有一枚文件**，自己写着"这一格推迟，本票只把边界冻住"；往外冒的消息只有 **9 种**名字，而且**没有序号、没有时间、没有轮次编号**，收集器是纯内存数组（进程一死就没了）。
- 不做的后果：这是**三件事的共同根**——"每一步的账可查（耗时／花了多少／输入输出）"画不出来、"点进去那一页"没有可导航的正文、"出事之后回放这一轮"做不到。补别的都得先补这一枚。

**差三："点进去"需要一个能导航的会话身份，我们今天给的是流编号。**〔做了半个，缺整块〕
- 别人怎么做：子代理被当成**一份真会话**（有它自己的会话编号）。**点行 = 主区直接搬进那枚子会话**；**点行尾箭头 = 在右侧另开一格装它**。那一页的正文**不是**"子代理专用小视图"，而是**把整套对话外壳原样装到它身上**——所以它的逐字冒字、工具调用、思考、图片，全走和主会话一样的渲染。而且**同一枚子代理不会被开成两页**（靠"种类＋内容编号"这个二元组去重）。
- 我们现在是什么样：那一行属于哪枚子代理，这句话**今晚才刚上线**；而且我们的编号是**以流为中心**（`subagent:<编号>`），他们的是**以会话为中心**（父亲会话＋孩子会话＋模式）。
- 不做的后果：界面顶多画出一列文本，**画完也做不到你说的那句"点进去"**——因为"点进去"需要一个能导航的会话身份，不是一行文本。⚠ 抄的时候有个坑：**只做主区顶替就等于少抄了他们那一形的一半**。

**差四：那两种看法没有第二种。**〔根本没做，且依赖差二〕
- 别人怎么做：任何一份会话（父亲的、孩子的都行）都能翻成第二视图——**逐事件台账＋一根可拖选的时间轴**：左到右是真实开始时刻和耗时，助手的条子区分"第一个字等了多久"和"吐字花了多久"，悬停半秒出精确值，拖选一段时间就只看这段时间里活着的行，滚轮缩放时间域。一行带 28 个可选位置，其中最值钱的几枚是：**能跳到源事件的那条线索、调用那一刻模型可见的工具清单、真实开始时刻、五个花费桶**。
- 我们现在是什么样：那一种"台账"在我们代码里搜 0 命中。
- 我们现在是什么样：台账那一层 0 命中；而**"点进去那一页"的正文今天靠名册行自带的流编号去认**（不需要新出口），所以这一格缺的只是"第二种看法"本身，**不是缺一条通路**。
- 不做的后果：它跑偏的时候，你**没有时间轴可以指认"就是从这一下开始歪的"**。⚠ 这一格里有一条**今天就能用的判据形状**：他们把**认证类错误的消息文本清空**再进界面，注释逐字写着"这类消息可能把密钥原样或半保留地带出来，绝不留在界面状态里"——**错误文本进界面之前先问一句"它会不会带凭据"**。

**差五：上限今天是写死在程序里的，设置页没有。**〔根本没做〕＋碰那张配置表，要你一句话
- 别人怎么做：设置页两半一次保存（"能派多深／能同时活几枚"和"子代理能用哪些模型"），但**两次写入相互独立**——被拒的那半留草稿并报失败，另一半照常落地；过期的草稿**报冲突并要求放弃，绝不覆盖较新的那份**。字段只有两枚，都带"必须是不带小数的安全整数、不许负零"这种校验。
- ⚠ 最要紧的是他们把**数口径写在数字旁边**：**"容量统计的是同一个主脑下面所有层级里还活着的子代理，主脑自己不计入；深度让位于工具自己的上限"**，每个标签旁一枚信息按钮展开规则，深度还配一张两行示例表。
- 我们现在是什么样：两个数字**写在程序里**，配置里搜"子代理"0 命中；你要放宽一次深度就得**重新编译**。
- 不做的后果：① 你会真的想做这件事；② 只放一个数字框而不写口径，人一定误读（他们连"主脑不计入"都要写成说明）；③ 更麻烦的是那枚 4 是**借来的天花板**，把它做成设置项等于开一条"从名册侧把上限调到桥之上"的路——**那正是我已经立票记过的那枚谎**。

**差六：父任务"我做完了"，孩子还在跑。**〔根本没做〕
- 别人怎么做：子代理还在跑时，父会话那条"空闲／完成"的通知**不发**，等带着结果重跑之后的那一次才算；检查不了才照发（有度的兜底）。
- 不做的后果：它会告诉你"完事了"，然后 3 分钟后又冒出一段结果。**信任就是这么丢的。**

**差七：校验型子代理会撞我们自己的刹车。**〔地雷，还没爆〕
- 别人怎么做：他们给"目标校验的那种子轮"**专门开了豁免**——因为它**反复调同一批工具正是它的本职**，不许提醒它"你在转圈"。
- 我们现在是什么样：我们的刹车只看"这一轮的签名变没变"，**没有"这一轮是什么意图"这个概念**（搜 0 命中）。
- 不做的后果：今晚子代理三层刚落地，**一枚校验型子代理天生会撞上那三级梯度**，然后被我们误判成跑飞。这颗要在它多跑起来之前拆。

**差八：状态分得不够细——但他们承认自己也分不细。**〔两边都缺，别抄成"他们更强"〕
- 他们那棵目录树自己登记了限制：**不区分**失败／被你取消／被拒绝／额度用尽／还没有一轮真正结束（这五种全显示成"非完成的静止"）；而且那个可点的名字**只是显示文本，故意不给"继续执行"的语义**（名字会重复、会改名）。
- 我们的名册行反倒有"这状态知不知道、不知道的原因"这两枚位置——**要补的是显示规则**：界面上今天还没规定"状态未知要显示'状态还不知道，因为……'，**不许把空状态当成'没在跑'**"。

**差九：上次怎么看它的，下次点进来还是那个看法。**〔根本没做〕
- 别人怎么做：界面在渲染之前**先读那份被存下来的"看法偏好"**——你上次用台账看子代理，下次点进来仍是台账。
- 不做的后果：每次点进去都要手动切一次视图，一天几十次。

### 3.3 你要转给界面那支的原话（逐字抄自子代理那张工单末尾那一节，不是我编的字段）

下面这段**你直接复制给界面那一支**。我不代转、也不绕那道尺（界面代码不在我这支的写面里）。

> ⚠ **工单文件名尾巴那句"go-side-has-zero-subagent-entity"从今天起是历史状态**：实体层＋载体层已入库。文件名**不动**（`-done` 后缀才是防重领的唯一键），**引用时以这一节为准**。
>
> **现象**：`internal/panel` 的 `TestApprovalCardViewJSONKeysMatchFrontendTypes` 今天红因**是两枚键**，红句逐字＝
> `Go Snapshot emits [instructions tasks] that interface PanelSnapshot does not declare`
> （`instructions` 那枚是项目说明那票带来的；**`tasks` 是子代理这票带来的**）。
>
> **转绿只有一跳**：界面那侧 `frontend/src/lib/panel.ts` 的 `PanelSnapshot` 补 `tasks?:` 一枚**对象**（Go 侧在 `internal/panel/composer.go:91`，带"没值就不发"的标记）。
> **不许**为过尺让 Go 少发一个键、也不许改尺或加豁免——那把尺判的就是"加字段必两侧同批移动"。
>
> **`tasks` 这一节的字段**（逐字取自 `internal/panel/subagent_roster_197.go`，21:5x 现读）：
> 节上＝`rows`（数组，**总是发**、可空）· `inFlightSlots` number · `poolCap` number（今天＝4，等于工具桥的并发天花板）·
> `streamTruncated` boolean · `streamElidedRunes` number · `droppedStreamKeys` string 数组（**总是发**、可空）；
> `rows` 每枚＝`taskId` · `label` · `kind`（`root`／`subagent`）· `parentTaskId`（根为空串）·
> `status`（**只用那 20 枚状态名**，有校验函数是判据）· `statusKnown` boolean · `statusReason?` ·
> `streamKey`（＝`subagent:<taskId>`；**同一包 `results` 节里 `correlationId === streamKey` 的那一条就是"点进去那一页"的正文**）·
> `blockedOnApproval` · `streamTruncated` · `streamElidedRunes` · `streamDropped`。
>
> **画的时候两件别做错**：① `statusKnown=false` 要显示"状态还不知道，因为……"（`statusReason` 就是那句原因），**不许把空 `status` 当成"没在跑"**；
> ② `streamTruncated`／`droppedStreamKeys` 是流被截断／被丢的实话——要么显示"这里少了 N 段"，要么明说没显示，**不许静默**。
>
> **入向那一跳今天不需要**（写腿现读结论，我复核过字节）：名册行自带 `streamKey`、正文走现成 `results` 节 ⇒ **没有新增任何面板方法名**。只有界面那支坚持要"宿主记住当前这格装的是哪枚会话"时才需要一枚入向方法——**那才是改约定的事，要另落台账再动**。
>
> **撤销口令**：界面那支若决定这版先不画名册，Go 侧把 `Tasks` 那枚键退回不发（**同批那两枚判据钉一起退**），"子代理上界面"那一格随之退回并具名记账——**不许留"键在、值恒缺"**。

顺带把另一枚键的形状也给你（同一跳里的第二枚，来自项目说明那一票，形状今晚换过一次）：`instructions?` 是一枚**对象**不是列表，里面 `status` 只取五值——**`loaded`（真加载了）／`none_found`（开着但目录里没文件）／`off`（你关掉了）／`refused`（路径被改写所以拒读）／`not_run`（这一轮还没跑到）**；`reason?` 是给人看的短句；`files` 数组**总是发**、可以为空，元素带路径／哪一层来的／深度／字节数／被裁掉多少／**整份被预算挤掉**（要能显示"这份没生效"）／并进了哪一份／来源名。
⚠ 界面**不许**把"键不存在"画成"已加载但为空"。

最后那一句"不许留键在、值恒缺"是我们这一版专门从 OpenChamber 身上学到的反面教材：他们家**有 6 处**"文案翻好了 9 条 × 14 种语言、4 枚设置键进了注册表，界面上零控件"。**这是我们唯一比他们强的地方（我们有 6 枚"写了也不管用的键直接响亮拒收"），补功能时别自己拆了。**

## 四、别让它自己转圈：今天我们只看得见一种转圈

先更正一句前提（这句是我自己在派单里写歪的）：**"我们有审批门，但没有'它自己转圈'这一维"——不成立。** 我们有三级刹车（第 3、5、8 次撞线加重，最高一级硬停并且**必须明说、禁止静默停**）。真正的差**不是"有没有"，是"粒度"**：粒度差一整层，而这一层差的是最常见的转圈形状。

**4.1 比的应该是"每一次动作"，不是"整轮"。**〔做了但只在一种形状下管用〕
- 别人怎么做：每一枚工具调用**各算各的短码**（工具名＋参数规范化），连着两次就记账、三次就提醒。
- 我们现在是什么样：把这一轮里所有动作**拼成一条长字符串**再比。
- 不做的后果：**模型只要每轮多带一枚无关的小调用，签名就变了，我们的三级刹车永远不会触发。** "它自己在转圈"这件事，今天我们只在"参数一字不变"时才看得见。这是本类目里最值钱的一条差。

**4.2 两个文件来回改（A、B、A、B）。**〔根本没做〕
- 别人怎么做：专门数批次交替，凑满 4 个连续批次就认。（有意思的是这一枚**只记账不提醒**——数到不等于要说，这个分寸值得学。）
- 我们现在是什么样：签名一变即计数重置为 1。
- 不做的后果：**"改一下、看一眼、再改回原样、再看一眼"这种最常见的转圈，我们既不会提醒也不会停。**

**4.3 同一类错误连续撞，而不是同一个错误重复撞。**〔根本没做〕
- 别人怎么做：错误先归一化成 **8 类**（超时／被限流／网络／认证／权限／找不到／参数不合法／进程退出），**先看结构化错误码，再退到文本**；文本截 1024 字符、只取首段、且限 4096。第 3 次同类就提醒"别再原样重试，换一条路，但也别因此断定整件事失败"。
- 我们现在是什么样：我们有错误分类（那是错误传播那一层的东西），但**分类不参与刹车**（搜 0 命中）。
- 不做的后果：**它换个参数重试一次，我们的计数就归零。** 于是一晚上撞 200 次同一类网络错，我们一句都没说。

**4.4 "到底改了没有"这件事，要有工具自己申报的证据。**〔根本没做〕
- 别人怎么做：工具申报三枚事实——状态变了没／产物变了没／有没有新事实。**有正向变化就当预期结果，不建"没变化所以可疑"的假说**（这一条分寸也对）。
- 我们现在是什么样：我搜了那三个词，命中 8 处，**逐名看全是 Windows 音频设备回调**，和工具进度申报无关。
- 不做的后果：我们的"重复"只是**形状重复**；他们判的是**没有产生新事实**——这是差一整层的判断力。

**4.5 有些重复是合法的，要开豁免表。**〔根本没做〕
- 别人怎么做：把"查后台任务状态""读后台任务输出"登记成**轮询类**，轮询**不触发**动作重复提醒，只在"游标不动 ≥3 次"时才提醒；`rg`/`grep` 退出码 1（没搜到）**判为预期结果，不算错误串**。
- 我们现在是什么样：刹车文件里**没有任何按工具名的豁免表**（搜"exempt"0 枚）。
- 不做的后果：**正常的轮询会被我们误计成跑飞**，而"这次没搜到东西"会被累积成"一直在犯错"。误伤两次你就会把刹车关掉——**那这道门就白装了**。

**4.6 被你拒绝掉的动作，不该算它转圈；但要把轮询的连续性清掉。**〔根本没做〕
- 别人怎么做：被权限挡掉的调用**从检测里整条剔除**，连结果和进度都不给检测看；**但**那一次仍会把轮询计数的连续性清零。注释逐字写着这件事为什么要分开做。
- 我们现在是什么样：我们的检测**根本不知道"这一枚动作是被拒的"**——被拒的动作走的是另一套流程（记账、然后不执行），它不进检测，但**也没有谁去清掉任何连续性**；而我们今天压根没有"轮询连续性"这一维（4.5 那张豁免表都没有）。
- 不做的后果：**你连拒 5 次，它被判成跑飞并硬停**——门控自己制造误伤。这条对我们尤其相关，因为我们今天到点该问的没人能答（拒与准都发生在无人处）。

**4.7 提醒话术自带"别把这条记成长期规矩"。**〔没查，标着〕
- 别人怎么做：每一套提醒文本后面都挂一段防污染后缀——"这是当前这一轮的临时提醒，不是用户偏好也不是长期规矩，**不要把它存进记忆、不要推广成技能或别的持久指令文件**"。
- 我们现在是什么样：**这一维本轮我没量**（我只量了没有频控表，没量有没有防污染条款）。诚实标出来，别当成"我们肯定有"也别当成"肯定没有"。
- 不做的后果：运行时提醒被模型当成规矩写进记忆，**一次误伤变成永久人格**。这一枚我们那套"间接提示注入防护"是同族顾虑，值得一并判。

**4.8 出误伤时不能一键关；关掉也不清计数。**〔根本没做〕
- 别人怎么做：一个开关（默认开，可远端覆盖，**读不到值就等于不覆盖，而不是等于打开**）；关掉时**清空累计**。
- 我们现在是什么样：那三级是配置常量，**没有运行时开关**（搜"是否启用"类命中 0 枚）。
- 不做的后果：误伤时你只能改配置重启；而"关了再开"会残留旧计数，行为无法解释。

**4.9 反过来：预算那一侧我们更全。**〔反向标，别读成"他们更强"〕
- 别人怎么做：那枚防跑飞的东西**自己不带任何预算刹车**——它的全部权力只是"往对话里塞一条待读消息"，注释逐字写着"至多一次、绝不拒绝工具、绝不中止一轮"。
- 我们现在是什么样：**令牌预算、50 轮下限、单工具超时、并发上限这四枚刹车都在我们这边**。⚠ 另有一处**取向差不是缺口**：他们四处"吞掉异常"，选的是"护栏永远不许伤害执行"；我们选的是"撞线必停"。
- 不做的后果（这里是"别读反"的后果）：⚠ 如果只盯他们那六枚信号，我们会以为自己"预算那一侧也缺"，于是**去补已经有的东西、或者把撞线必停改成温和提醒**——后者要过那张状态转移表，属要你一句话的级别，**不该被一次对标顺手改掉**。

**4.10 刹车留下的短码，别用明文。**〔根本没做〕
- 别人怎么做：每一轮换一把随机密钥打短码；入参先规范化（对象键排序、深度上限 32、键数上限 1024、**非纯对象／带原型／循环引用一律拒收**）；**超过 16KB 预算就整条不检测**（而不是截断，因为截断会让"同一枚长参数"看起来像两枚），并计入"跳过了几枚"，最后进那一轮的小结。注释逐字："原始键绝不离开这一轮、也不给观察者看"。
- 我们现在是什么样：我们把"工具名｜参数"**明文拼进内存**。参数里如果有密钥、有文档正文，内存里就留了一份明文副本。
- 不做的后果：这是一枚**安全面**的差，不是体验差。我们那套"敏感路径"的规矩管的是磁盘，这里管的是内存。

**4.11 能不能回答"这道新护栏上线后省了多少"。**〔根本没做〕
- 别人怎么做：有一枚**离线回放**，用**同一套生产判断逻辑**重跑历史轨迹（注释逐字："回放不下指令、没有写盘副作用"），并量化"信号之后又多烧了几步／几枚工具调用／多少令牌"。
- 我们现在是什么样：我们跑的是"给一串固定输入看输出对不对"，不是轨迹回放。**但原始数据我们已经有了**——动作记录里已经带"判定／结果／错误类别"三列。
- 不做的后果：这条对我们最实际的用处是**钱**：我们那张资源上限表每次被问"这条约束到底值不值"，今天只能靠嘴说。这是一条几乎免费的证据链。

**4.12 遥测里要带"策略是哪一版"。**〔根本没做〕
- 别人怎么做：每一枚上报都带 `policy_version`（现值逐字 `runaway-v1`），载荷是白名单投影（只出版本、会话号、轮次号、信号名、第几步、第几次）。
- 我们现在是什么样：全仓搜这两枚版本号名字 0 命中。
- 不做的后果：**我们把三级从 3/5/8 改成 4/6/10 之后，历史数据分不清是哪一版策略产的，回滚时无法归因。** 这条很便宜，但越晚补越贵。

**4.13 你按了停止，要同时告诉模型。**〔半缺；而且是我们今天就能自己做完的一枚〕
- 别人怎么做：后台任务的停止控件是**两击**（第一击上膛，3 秒内第二击才真停），而且**明确告诉模型"用户停止了你的任务"**——注释逐字写"这次停止不在模型的播报台账里认领任何东西，主脑照常收到标准完成通知：**模型被明确告知是人停的，而不是留给它去猜**"。
- 我们现在是什么样：我们只管**告诉人**（那条"绝不静默停"的规矩在），**告诉模型**那一半 0 命中；两击上膛停止在 Go 侧**0 个生产落点**。
- 不做的后果：**你按了停止，它下一轮看到的是"任务自己结束了"。** 这不是体验问题，是**正确性问题**——它后面所有判断都建立在"它以为自己说完了"上面。⚠ 这一枚不碰任何要你批准的东西，纯自家活，是我今天能自己收的第一枚。

## 五、"要批准"和"要回答"：同一个洞的两面

今天最疼的洞还是那个：**到点该问你的，没人能答**。上一版我报过"三种答复入口零调用者"。这一轮把两面都查清了，结论是**缺的不是审批卡，是那两个动词**。

**5.1 它想反问你一句，整条路都不存在。**〔根本没做〕
- 别人怎么做：模型可以使出"问人一个问题"——带**选项**、可多选、可自己写答案、可跳过、可关掉。⚠ 而且"跳过"和"关掉"是**两种不同的东西**：跳过＝给这一项交一份空答案继续往下走；关掉＝取消整个等待（两枚不同的取消码：宿主撤走／人关的）。题号、已选、自己写的内容**只放在不持久的临时存储里**，绝不写服务端、绝不写浏览器本地存储、绝不写磁盘。同一时刻**只有一枚问题拥有输入框**，后面的问题留在会话里等前一枚落定。有一枚问题专门给"计划评审"用，**批准那一项是按名字点名的，不是按位置**——注释逐字："按名字而非按位置，免得界面从顺序里猜结论"。
- 我们现在是什么样：搜"问用户"这一族词，**0 命中**。
- 不做的后果：**它拿不准的时候只能猜，猜错就白烧一整轮，而且烧完了还不会告诉你它当初在赌。** 你自己想想：你请人办事，对方拿不准时不问、直接猜，你什么心情。

**5.2 界面上没有"就这一次"这个动词。**〔根本没做，而且这一条**不是我们更严**，别读反〕
- 别人怎么做：面板只给**临时决定**——只有两枚：`允许一次`／`拒绝`。他们 README 逐字划界：**"持久权限策略仍由服务侧那一侧拥有"**。另一家把"一直允许"**要存成哪条规则直接印在按钮上**（文案逐字 `Always: {patterns}`），还有一家在按钮上给"一次／一直／拒绝"三枚并带二次确认。
- 我们现在是什么样：审批卡视图字段有 **11 枚**，比他们那 5 枚**多**（我们多"命中了哪几条写死的规则""没有理由时不许渲染成'没风险'""这一票来自哪一侧""孩子链""会话级放行被挡住"）；应答出口是**闭集 4 条**（球／Esc／面板／语音取消词），其中**语音否决这一维他们 52 个界面包里没有任何对应物**。⚠ **但面板那一侧只能拒绝，"允许"被结构禁掉。**
- 不做的后果：你第一天自用就撞两难——**要么永久放宽，要么每次都拒。**
- ⚠ 这一格我该问的方向**不是**"要不要学他们放开面板"。真正该拍的是：**"允许"这个出口该落在哪一层**——原生卡片？球的长按？语音取消词的反义词？这一问属你一句话的级别，**我不动，只把它标出来**。

**5.3 "一直允许"要让用户看见"会存成哪条规则"，而且宽度该是一枚可选的东西。**〔做了但只在名字里存在〕
- 别人怎么做：点"一直允许"时**不是写死一条规则**，而是**一次列出几档宽度供你挑**：最窄／按第一个词／按前两个参数／按域名／整个工具。有一条**向后兼容铁律**：**第一档永远是最窄的那个，和老行为完全等价**；要拿宽档，客户端必须**明确回一个"我选第几档"**。每一档带可翻译的标签键和参数，于是**宽度是机器能读、能排序、能统计的一份名册**。一个待批主体＝一组；一条复合命令里有几枚要问的，就有几组。
- 我们现在是什么样：设计文档里手写着三档（仅本次／本会话允许向此应用注入／本会话允许向所有应用注入），**而且只针对一枚工具**；"会话级放行"这个词在代码里**只有词表里的名字和注释，没有任何真产出它的地方**。
- 不做的后果：今天我们加一档**只能改文案**；宽档**无法被审计、无法被回滚、无法按档统计**。这条是本轮对我们"批量授权"那一格最直接可抄的东西——它把三个按钮升级成了可管理的对象。

**5.4 拒绝要分三种心智。**〔根本没做〕
- 别人怎么做：**给人看的那份理由本地化**（三枚逐字：已允许／需要确认／已拒绝，中英各一套），**给模型看的那份前缀固定英文**（注释逐字："这样模型和日志检索在任何界面语言下都能解析出来源"）；拒绝来源分四枚：**你拒的／规则拒的／安全墙挡的／连绕过档都拦不住的那类**。他们自己还立了一条硬规矩：**新增一条判据就必须同时新增它的文案，漏一条编译不过**。
- 我们现在是什么样：我们没有这种带来源标签的拒绝文本（搜 0 命中）。
- 不做的后果：① 你分不清"我拒的"和"它被墙挡的"，于是你以为自己放开了、其实没有；② **模型不知道该换条路还是该放弃**；③ 而"新判据必须有文案"这条，我们完全可以照抄成一枚"少写一条就编译不过"的检查，成本极低。

**5.5 现场没有能答的人，就直接拒绝。**〔根本没做〕
- 别人怎么做：他们的一档不是"松／紧"一个开关，是把"这一档允许做什么"**拆成四枚互不相干的开关**（要不要问人／能不能用二次判定／权限层是否参与阻断／能不能绕过）。其中"要不要问人"那一枚有一个专门取值：**没有能答的人就当场判拒绝**，理由文案逐字："需要用户确认，但没有可用的批准通道"。⚠ 而且"权限层不参与阻断"和"永不问人"是**刻意分开的两回事**；"可以绕过"那一档也不是不问，是**照样走完整个判定，只是把"要问"折成"允许"**。
- 我们现在是什么样：我们搜"没有批准通道"这一族 0 命中。
- 不做的后果：**这一枚正面就是我们那枚"深度睡眠拓扑"的空格**——球常驻、面板没开、语音没接，这时候它要最严那一档，今天的行为没有定义。而且**对子代理同样有效**（子代理不许自带允许出口，那它卡在等批准时、又没人能答，算什么？）⚠ 这条和"到点该问的没人能答"是同一族的另一半。


**5.6 判定次序里有两条反直觉的，值得钉进我们的表。**〔取向不同＋要补一半〕
- 别人怎么做：一条 14 级的判定次序。两条最要紧：**① 某条命令自己的死拒，赢过一条更宽的"要问"**（注释逐字："否则加一条宽泛的问，会把针对某命令的死拒削弱成可以问人"）；**② 检查器自己抛异常 ⇒ 问人**（失败关闭）。
- ⚠ **但他们有一级是"没注册检查器的工具默认放行"**——而我们的兜底是"没有判定器可用或判定器崩了 ⇒ 失败关闭、升到最严档"。**在"最坏情况谁更保守"这一问上我们更严**，这条不许被"他们档位更多"读歪。他们的真实答案其实是三段：未注册工具先按"参数里能不能提出路径意图"过一遍能力兜底，兜不住才放行，**而写类工具（打补丁那种）反而在提不出路径意图时问人**。
- 我们现在是什么样：我们的兜底**比他们更严**（没有判定器可用、或者判定器崩了 ⇒ 失败关闭、升到最严档），**但这两条反直觉的次序我们都没有**：没有"某条命令的死拒赢过一条更宽的问"这一级，也没有"检查器自己出错就转成问人"这一支。
- 不做的后果：**我们日后把命令行包装类插件接进判定时，"没有判定器的工具算哪一档"必须自己拍死**，不能靠"默认放行"糊过去。

**5.7 权限层可以改写要执行的命令——我们完全没有这一维。**〔根本没做〕
- 别人怎么做：判"允许"的时候**可以把命令改掉再执行**（目前一种：把不可回收的删除**改写成丢进回收站**），给人看的理由逐字："已允许：这条删除命令被改写成可回收删除。原命令是……"。跨层递这件东西**不靠参数字段名约好**，靠一枚**不可伪造的记号＋冻结对象**，读取端做全量类型复核，注释逐字："只有字面量给出的回收站目标跨这道缝，运行器自己掌握启动器、脚本路径和环境"。而且**"改写到底生效没有"是一枚单独钉住的读数**。
- ⚠ **同时这一格里我们是领先的**：他们自己写下 Windows 缺口——"命令行发起的删除在 Windows 上**完全跳过回收站、不可恢复**；在改写通路为 `del`/`rd`/`Remove-Item` 接通之前，最安全的策略是硬拒"。**而我们已经做了那一条改写通路**：走系统调用、带"允许撤销"旗标，**并且回读回收站里的恢复记录来证明它真的进了回收站**，注释逐字："这条路永远走不到直接删除：删掉不等于进回收站"。**这一格必须在差集里反向标。**
- 我们现在是什么样：我们的权限层**只能选允许或拒绝，不能改道**——它没有"把这枚命令换成另一枚去执行"这个能力；**而恰好是他们缺的那半（Windows 的删除进不了回收站）我们做完了**。
- 不做的后果（抄那一维的价值）：你不用在"拒绝它干这件事"和"让它干一件不可恢复的事"之间二选一——**可以批准它干、但干成可反悔的版本**。

**5.8 同一条命令在不同外壳里语义不同，"我看不懂这条"要有一等名字。**〔根本没做〕
- 别人怎么做：判定输入里带**平台**和**外壳家族**（posix／cmd／powershell／unknown，默认 unknown）；命令先被归成一枚中间表示，5 种种类里**"我解析不了"（不透明）是一等公民**；路径值带四枚位置（原文／解出来的／**是否动态**／怎么解的：绝对／相对／家目录／环境变量／通配／未知），**"动态"明确写着"环境变量或通配还可能改变语义"**；多枚意图的聚合是**死拒 > 不可绕过档的问 > 普通问 > 放行**，并且**要扫完全部**而不是取第一个非放行（注释解释得很直白：早期一枚普通"问"会遮蔽后面的"不可绕过档的问"，于是绕过档就把敏感写放过去了）。
- 我们现在是什么样：我们有 shell 规则文件，但**"不透明"和"外壳家族"都不是一等输入**（搜 0 命中）。
- 不做的后果：**同一条命令在 cmd 和 PowerShell 里根本不是一回事**（引号、变量展开、管道全不同）。我们的规则表今天没有这一维，于是**一条规则只能对一半的外壳成立**。

**5.9 敏感路径那张表，可以直接当我们的起点。**〔有现量，值得抄结构〕
- 别人怎么做：一张**死拒 15 类**＋**软风险 12 类**的确定性表；⚠ 关键分寸：**15 类里只有 10 类是"最终拒绝"，剩下 5 类（系统密钥／敏感读／ssh 凭据／编码绕过／反向 shell）是"连绕过档也必须问人"而不是死拒**——这比我们的"敏感路径直接拒"**多了一个"敏感读可以问人"的中间态**；软风险那 12 类**踢给二次判定**。正则表**已经含 Windows 目标**：`.ssh` 各型私钥（显式排除 `.pub`）、`.aws/credentials`、`/etc/shadow` 等、私钥词干＋`.key`、`.p12`、`.pfx`、`private*.pem`、macOS 钥匙串、`/proc/*/environ`、**`System32/config/SAM` 与 `NTDS/`**，注释写着"命令文本里两种分隔符都认"。另有**两张"读"侧表**和一枚专管 `printenv` 这种**不带路径的泄密形态**的匹配函数。
- 我们现在是什么样：我们的红线表是**规则散落着拼起来的**，没有"死拒层＋软风险层"这种两层名册，也**没有单独的读侧表**，更没有"不带路径的泄密形态"（比如把环境变量整份打出来）这一枚匹配。
- 我们现在是什么样：我们的写死清单**有"直接拒"和"要问"两种，但没有"这一类连绕过档都不许绕"这第三档**，也没有单独的读侧表和"不带路径的泄密形态"这一枚匹配；⚠ 而且**我们的表里 Windows 那一半是薄的**（接合点、同步目录这些我们有专测，但没有一张逐类的敏感路径名册）。
- 不做的后果：我们自己那张红线表现在是靠散落的规则拼的；**"确定性两层表＋读侧两张表＋不带路径的形态"这个结构，比逐条加规则更能防漏**。

**5.10 要不要把二次判定搬到云端：这两条账不能互相冒充。**〔取向不同，且属你一句话〕
- 别人怎么做：软风险踢给**服务端**判定。载荷里带**整条工具入参原样打成的包**＋平台＋家目录＋工作区根＋**渲染过的最近对话**（最近 3 条用户消息，超 500 字符则首尾各留 250；再加整会话最近 5 条各截 200；工具调用压成"工具名＋截断参数＋截断结果"）。裁决词表三枚＋客户端自己合成的第四枚"超时"；**非 2xx／非 JSON／业务码非 0／裁决不合法／网络错／中止——全部折成"超时"**，然后**弹一张问人的卡**，注释逐字："网关不可用时绝不静默绕过用户"；单请求 60 秒超时；还会**区分"真超时"和"网络错"以便卡片说实话**；只在托管运行时启用，注入缝是接口，**离线或自带密钥的部署可以塞一枚恒"超时"的空实现把流程逼回问人**。
- 我们现在是什么样：设计文档把这类双轴判定整条挂在"保留"上，理由是**每次多一枚模型调用且在响应路径上（+300–800 毫秒）**，与我们的延迟预算相左，并写了重评触发条件。
- 不做的后果（这条要说清方向）：他们那一枚**搬到了服务端**，所以**不占我们最在乎的本地响应路径预算，但把"你的整条工具入参＋最近对话"送出了机器**。**我们若抄"二次判定"：在本地跑，那条延迟论证仍然成立；走云端，就得另开一条隐私账。两条路不能互相冒充对方。**属你一句话的级别。

## 六、钱与证据：出事之后能不能自证

这一节全是"平时看不见、出事时救命"的东西。你不懂这块，但**每一次我们说"这不是我们的 bug"，靠的都是这一节的某一件**。

**6.1 每一轮"实际喂给模型什么配置"，要留一份证据。**〔根本没做〕
- 别人怎么做：有一枚专门的记录，**不含消息正文、不含密钥**，只存"重建这一轮需要哪些入参"：系统提示、工具清单（每枚的名字＋说明＋参数形状）、模型、服务商、接口、思考档位、输出上限、宿主自己的输出上限、输入打包上限、缓存保留策略、输出格式要求、输出修订指令。存法很讲究：规范化后的定长文本＋**短码去重**（同样的入参不存两份）、单枚上限 4MB、短码表上限 256 条、**原子替换**（不留半截文件）、**压缩完成后把当前这份冻结在它描述的那一轮旁边**、**反悔之后删掉的是上一轮的证据、不是运行配置**（注释逐字这么写）、同一条会话排好队一条条写。
- 我们现在是什么样：我们有提示词落盘和超长溢出到文件，**但没有"这一轮的运行时配置"这一枚独立证据**。我搜了那三枚具体位置名，命中的 3 处全是"模型能支持哪些档位"的清单，**不是"这一轮实际用了哪一档"的读数**。
- 不做的后果：**出问题时你要回答"当时到底喂给模型什么"，今天只能靠读代码反推。** 举一个真实的形状：它突然开始乱砍自己的输出，你想查"那一轮思考档位是不是被改成了最低档"——**今天查不到，因为那个数只在内存里活过一次。**

**6.2 中文的字数换算成模型"字数"，我们今天低估了 1.3–2.7 倍。**〔做了但会咬人；本轮我认为最该先修的技术风险〕
- 别人怎么做：他们把这件事**写进源码注释并点名后果**——按"每 4 个字符算 1 个"会**低估 4–8 倍**（汉字实际每个吃 1–2 个模型字），而低估会把"该压缩了"的那条线推到右边，**推到兼容接口的服务商直接把请求打回**（他们逐字点了自家某型号"输入超过窗口减输出上限就拒绝"）。
- 我们现在是什么样：我们就是**字节数除以 4**。中文每个字 UTF-8 占 3 字节 ⇒ 算出来约 0.75 个模型字，实际约 1–2 个，**低估 1.3–2.7 倍**（这个算术是我本人算的，方向和他们的注释同向）。而且**每一条预算阈值都要过这个函数**：历史压缩触发线、刹车的预算上限都在射程里。
- 不做的后果：**长中文会话会被服务商一口回绝**，而且报出来的错看着像"窗口不够"，实际是我们自己算错了数。⚠ 我们是**中文优先**产品，这条对我们比对任何一家都更疼。

**6.3 估错了没关系，但只许错在尾巴上，并且要说这数是估的还是真值。**〔根本没做〕
- 别人怎么做：往回找**最后一条成功且带真实用量**的消息，**信它上报的总数当"前面所有"的值**，然后**只估它之后的那些**；估的默认取向是**故意偏高一点**（注释逐字："宁可早触发，这是我们想要的方向，因为容量算错的代价是一次硬邦邦的拒绝"）；每条计数**把来源写进结果里**（"服务商告诉我的"／"我自己估的"／别的），**来源是值的一部分**；还给每条消息加 4 个字的固定包装开销、图片块按 **4800 字**计费、超长的连续字母数字串按上界算。
- 我们现在是什么样：我们逐条消息累加估算，**不锚定上一条真值**。
- 不做的后果：我们**每一轮都在重新估前面一整段已经发生过的历史**，误差会累积、会来回摆。⚠ 这一格和 6.2 是同一枚票的两半，分开做会做两遍。

**6.4 压缩之后，那份摘要要带"后面这些条目的用量已经过期"。**〔根本没做〕
- 别人怎么做：摘要里专门存一个条数，注释逐字："这些是保留下来的旧上下文里的消息，它们的用量已经过期。**把它和摘要一起存下来，恢复历史时才有同一条界线**；老数据没有这一枚，就只能改用时间戳来判断新鲜度。"
- 我们现在是什么样：我们的摘要**没有这个条数**，恢复历史时也**没有一条用量界线**可对齐。
- 不做的后果：进程重启、历史恢复之后，**它会拿一份过期用量继续算钱**，而且你分不清是从哪一条开始算错的。

**6.5 "要不要压、为什么这次没压、压完前后各多少、压失败了为什么"——四件事各自要有读数，并且压之前可以先推掉这一次。**〔根本没做〕
- 别人怎么做：四枚观测各自带**阶段**（好归因是哪一段崩的）；还有一枚**压缩前的检查点回调**——只在"确实需要压、也已经有了安全方案"时才叫，**返回"不"就这次先不压**（这是给"正在写盘／正在等批准"这类时刻留的闸门）。触发线本身是两条：一条主动线、一条服务商硬上限线，**主动线永远更早**，并且按窗口比例封顶；某个型号的大窗口模式另开一条按产品定义的 90% 线。输出预算还会**随上下文变胖而自动缩小**，但有个地板。
- 我们现在是什么样：我们是"按配置窗口等比缩放"（这是设计里明确要求的、不是优化），**没有这两条线、没有阶段读数、没有压缩前闸门**。
- 不做的后果：**两种哲学打架时没人能解释为什么这一轮压了／没压。** 而且这是唯一一处"我们随窗口等比缩小、他们给绝对余量＋按型号开特例"的分歧，以后对不上账时你会来翻这一条。

**6.6 "跑完了但还没告诉会话"必须是一列能查的账。**〔根本没做〕
- 别人怎么做：任务对象上带"什么时候送达过"，并且查询**可以只取"跑完了但还没送达"的那些**；落库时这一枚是**真实的一列，而且数据库为"按会话＋按状态＋按有没有送达"这一组问法专门建了查得快的目录**。⚠ 这一枚就是他们那句许诺（"后台任务跑完会自动通知你、这段对话会自己续上"）背后**兑现它的机关**。
- 我们现在是什么样：名册是**进程内一张表**（注释逐字写着"进程本地"），没有"送达"这一维。
- 不做的后果：**"完成通知到底送没送出去"今天无人记账。** 这是我们那一串"回执要说实话"老问题的**同一个根**：没有一条持久的事实源，回执就永远只能靠猜。

**6.7 断电重启之后，孤儿任务要有"丢了"这个正式状态——而且不许拿"它很久没动了"当证据。**〔根本没做，连这个状态名都没有〕
- 别人怎么做：状态一共 7 枚，**"正在停"和"丢了"都是正式状态、不是错误码**。"丢了"的来历是：重启后发现宿主进程不在了 ⇒ 落成"丢了"＋带上错误码＋发一条完成事件。⚠ 他们把判据钉得极死，注释逐字：**"只有'这一轮确实没活下来'的精确证据才允许结算；年龄、或者会话空闲，都不能证明归属丢失。"**
- 我们现在是什么样：那张多任务名册**注释逐字写着"进程本地"**，状态里没有"正在停"也没有"丢了"这两枚，**取消失败无处可说**。
- 我们现在是什么样：那张多任务名册**注释逐字写着"进程本地"**，状态里没有"正在停"也没有"丢了"这两枚，**取消失败也无处可说**。
- 不做的后果：**崩溃或重启之后，后台任务和子代理在账上要么消失、要么停在"还在跑"的假状态。** 你会盯着一个已经死了 3 小时的"进行中"看。
- ⚠ **抄的时候有一条陷阱必须写进判据**：他们停不下来时**照样落"已取消"**，只在事件里带一枚"停止失败"的旗。**抄状态、不抄那枚旗 = 我们自己造一枚"账上已取消、实际进程还在"的假终态。** 同理：**取消这件事"失败了"要能表达**——我们今天缺的不是取消能力，是"取消没成功"这句话。

**6.8 每枚任务自己带着"烧了多少"。**〔根本没做〕
- 别人怎么做：用量（输入／输出／合计／花了多少钱／附加信息）是**任务对象上的字段**，不是另算一张表。
- 我们现在是什么样：任务记录**六个字段里没有花费、也没有钱**；而且价格参数今天没真传进环路，界面成本恒显示"未计价"。
- 不做的后果：这条和半拉子账里那枚"价格、预算参数今天没真传进环路 ⇒ 成本恒显示未计价"是同一件事的两头：**一头没传进去、一头没地方存。**

**6.9 定时那一格：他们重启后逐枚重登记，但"错过的档期不补跑"。别把这写成"他们已经解决"。**〔取向不同＋缺一格〕
- 别人怎么做：每枚定时任务**一个 `.md` 文件**（头部是设置、**要跑的指令写在正文里**），启动时扫盘逐枚重登记；⚠ 我让他们查的那几个词（逾期／补偿／错过的／漏发）**0 命中**，重启登记时"上次跑是什么时候"一律写空 ⇒ **"每天 9:00"那条如果 8:55 崩了、9:30 拉起，9:00 那一次不会补。**
- ⚠ 但有一枚**我们完全没有的形状**值得抄：启动时可以选 **"隔离恢复"**——**从别的机器／别的副本恢复来的那份档期表，先只登记供查看和供用户修改，不执行**。
- 我们现在是什么样：设计里明确"应用内零调度器，定时交给系统"（这是**取向**，不是缺口）。
- 不做的后果：**"OS 定时唤起的这一次运行，能不能带一份'只列不跑'的档期表"——我们的方案里连这一维都没讨论过。** 一旦我们把定时交给系统，"从备份恢复来的定时任务立刻开跑"就是必然发生的事。

**6.10 忙的时候，那一次定时任务去哪了——要有五种结局，不能只有一种"发出去了"。**〔根本没做〕
- 别人怎么做：排队队列里**最多活 30 分钟**，排空结果五枚名册：**送出去了／过期了／被撤了／被更新的顶掉了（同一件事只留最新那次）／失败了**。而且**排空触发不是"只有会话正常结束"**（注释逐字："否则它就永远坐在队列里"），并且**按事件来源白名单过滤**——他们逐字举了例子：**标题生成服务发出的那条"出错"不许把定时队列排空**。
- 我们现在是什么样：**没有"定时撞上手上的活"这一形**（应用内零调度器），所以既没有这套结局名册、也没有"谁发的错误可以排空队列"这一维——我们的会话排队管的是另一件事（谁占着某个目录）。
- 不做的后果：9:00 的活儿撞上你正在聊 ⇒ 今天我们没有这套结局名册。⚠ **更要紧的是那一枚"来源过滤"**：这正是我们那类"内部杂事的失败被当成用户的任务失败了"的形状。**"被更新的顶掉"那一枚也直接对得上你问过的"每个周期任务只补最近一次错过的"。**
- 顺带：跳过要说得出**是哪一种跳过**（关了／不在时段内／时区写错了／上一次还没跑完）——**时区配置非法是一枚单独的原因，不是悄悄跳过**。〔根本没做〕

**6.11 排队中的那一次也能撤。**〔根本没做〕
- 别人怎么做：除了"删掉这个定时任务"和"停用它"，还有一枚**"把已经排在队列里的那一次撤掉"，并且返回撤掉了几枚**。
- 我们现在是什么样：**"定时撞上正在跑的这一轮"这一形我们整个没有**（应用内零调度器），所以也没有"撤掉队列里那一次"的出口。
- 不做的后果：你改了主意，但今天九点那次已经在队列里了——**你只能等它发生。**

## 七、快捷键：不是从零做，是"一条已存在的链缺最后三件配套"

先说结论（**这就是那条把你坑过的更正**）：**〔做了但没人接上〕，不是〔根本没做〕**。底座我已经在第一节和第三节外面量清了：4 枚可改键、改了自动重注册的桥、注册成功的可读报告、以及**你本机 84 枚候选组合的占用实测**。下面只列缺的。

**7.1 缺一张"能绑哪些命令"的目录窗。**〔根本没做〕
- 别人怎么做：一扇窗列出**当前这个窗口能用的所有命令**，可以按操作名／英文名／**当前键位**搜；可以现场录制、清除、恢复默认。核心操作用**固定的产品顺序**，**不受插件注册、卸载、重新挂载影响**；没进这份顺序的扩展命令按命令编号稳定排在核心之后。
- 我们现在是什么样：**没有一份"能绑哪些命令"的名册**（代码里只有通道常量，没有一枚能列出来的命令目录）；界面那一支有没有那一扇窗我不读不转述〔未量·界面地界〕。
- 不做的后果：⚠ 这一格最阴的地方在于：**我们的可改键今天只有 4 枚，而它们不在任何一份能看见的目录里。** 你今天不知道自己有几枚键能改，就等于没有。

**7.2 缺录键的规矩——他们的规矩细到可以直接当判据抄。**〔根本没做〕
- 别人怎么做（逐条都是判据形状）：最多录**一至两枚按住时间重叠的非修饰键**＋修饰键，**第三枚直接拒**；**松开第一个键就当场保存当前组合**（所以先后按 A、B 只会录进 A）；**保存会拒掉已被可编辑操作或固定操作占用的组合**（包括互相重叠的单键和双键）；**写失败时保留录键框的焦点和草稿，可以直接重试**；松开非修饰键之后**可以直接录新的，不必再点一下框**。
- 我们现在是什么样：注册侧的读数有（"哪些键注册成功了"查得出来），**校验侧一枚都没有**——同一个词命中的 14 处逐名全是"注册"，**没有一枚是"用户改键"侧的检查**。
- 不做的后果：没有这套规矩，改键这件事的体验一定是"我按了没反应"或者"我把它撞掉了别的"，而这两种都查不出来。

**7.3 缺"读不到时不许静默"。**〔根本没做〕
- 别人怎么做：键位配置**读失败时禁用编辑，并用系统提示说清当前在用哪套键、受影响的是哪份配置位置**；内容损坏时**先备份再修**；**如果这份配置是被更新版本写的，就提示要升级程序**；⚠ 而且**"恢复全部默认"不覆盖那些读不懂的数据**。
- 我们现在是什么样：**没有这套"读不懂就明说"的处理**；我们的强项在另一处（写了不管用的键会响亮拒收），但那一面**管的是设置键，不管键位文件读不读得懂**。
- 不做的后果：**"我点了恢复默认，结果你把我另一套配置清了"**——这是最难看的一类事故，而他们把它防住了。

**7.4 缺"自定义了多少项"这个数。**〔根本没做〕
- 别人怎么做：窗底显示"恢复全部默认"＋**当前运行环境和本平台的自定义项数（包括已经被移除的绑定、和当前没挂上的命令）**；没有任何自定义项时**隐藏这个数并把那枚操作置灰**。
- 我们现在是什么样：**没有"当前几处自定义"这个数**；而且更根本的是——**改键这件事今天没有入口**（只能手改配置文件），所以"自定义了几处"暂时无人可问。
- 不做的后果：⚠ 注意他们把"已经不存在的键位"也算进自定义数——这一形是**"我改过什么我自己都忘了"**的唯一解药。

**7.5 缺真实宿主里的接线（这一条是第三种"没有"）。**〔做了但没人接上〕
- 别人怎么做：他们那套里"录键的那扇窗"和"键真正生效的地方"在同一个装配里，不存在"做好了但没装上"这一形。
- 我们现在是什么样（读数）：那条"改了自动重注册"的桥，全仓**只有一个生产调用者**，在一枚调试小工具里；产品入口 **0 处**。
- 不做的后果：**你现在改配置里的键，产品不重启就不生效**——虽然代码已经写好了"改了会自动重注册"这件事。这是**最便宜的一枚**：补一行装配。

**7.6 ⚠ 有一条不是缺功能，是缺策略，而且必须你拍一句。**
- 别人怎么做：把快捷键分成"能改的一堆"和"永远不许改的一堆"两份名册，安全相关的钉死在第二堆里（上一段引的三条原文就是他们那份"永远不许改"）。
- 我们现在是什么样（事实）：`取消`这枚可改键今天就是 `Esc`，而我们的规矩钉着"`Esc` 在等确认期间临时接管、会话结束必须把原绑定还回来"；同时 `Esc` 还是**四条应答出口之一**。
⇒ **一旦"取消"这枚键可改，那条规矩的前提就变了——它假设被临时接管的就是 `Esc`。**
他们那一形里的答案是现成的：**等批准的界面挂着的时候，`Enter` 和 `Esc` 不许分配给任何可编辑的快捷键**；而且"审批"和"按两下 Esc 停止"这两行**在快捷键目录里是不可改的贡献项**。
⇒ 一句话总结这个形状：**"能改的一堆"和"永远不许改的一堆"要分开摆，安全相关的那几枚进"永远不许改"那一堆。** 我们已经有这个形状（四条应答出口是闭集），**只是没人把它说成快捷键策略**。这一格请当成**缺策略**处理，不是缺功能。
- 不做的后果：**要么一直不敢开这个口（那四枚键永远只能手改配置文件），要么把口开了之后那条"等确认期间临时接管、结束必须归还"的规矩前提悄悄没了**——两种都比先定一句策略贵。

## 八、面板那一页的手感与几何

这一层最容易漏，因为它"不是功能"。但**你每天骂的都是这一层的症状**。

**8.1 谁让位、按什么顺序让位，要写死。**〔根本没做，而且只能我们自己拍〕
- 别人怎么做：三栏外壳，**所有数值都在明处**（中栏最小 400、左栏 264–420、默认 280、收起 56、窗口窄到 1024 自动收起、右栏最小 300、默认占 45%、最大 70%）；**确定的挤压次序**逐字写着："为了给中栏留下 400，框架**先**把右侧面板缩到 300，**再**报告空间不足让占用方自己关闭，**最后**才进一步压缩中栏"；变宽**不自动重新展开**，全屏时藏起拖宽的把手但**不自己释放轨道**。
- ⚠ 还有一格专门管"窗口边那条能不能拖"：**每一行 chrome 自己声明自己是可拖区，于是这一行的空白处能拖、行里的控件照样能点**（不是整块标题栏设成拖动区）。
- 我们现在是什么样：Go 侧不产这类数；球那侧有一条"全屏时藏起来"的规格，但那是球不是面板。**"谁声明拖拽几何"这一格我没量到**（属界面那一支的地界，我不读不转述）。
- 不做的后果：**我们有面板＋球两块面，比他们多一层；而他们只写了"右栏 vs 中栏"两级次序，没写"贴边面板 vs 悬浮球"**。⇒ 这一格是**我们必须自己拍的空格，抄不来**。

**8.2 没用到就别长控件。**〔根本没做〕
- 别人怎么做：后台任务那一格**在会话里至少看得见一枚任务之前什么都不渲染**，注释逐字："因此普通对话不会为未使用的能力长出控件。"
- 我们现在是什么样：刷给界面那包内容是**固定四／五块**，长出来那一块（子代理名册）也是靠"没值就不发"来藏的。
- 不做的后果：⚠ 这一条和第三节那条"不许留键在、值恒缺"是**同一枚病的两面**：控件不该为没接上的能力长出来，数据也不该为没画的东西发空壳。

**8.3 展开面板复制的是"命令"，不是"输出"。**〔根本没做〕
- 别人怎么做：那一格里点复制，**复制下来的是那条命令本身**（可以直接粘去别处跑），而正在展开看着的输出流**跟着展开／收起／卸载／弹层关闭一起开合**（不看的时候不占资源）。
- 我们现在是什么样：**〔未量·界面那一支的地界〕**我只能量到源头那一半——我们的"后台跑着的那一枚"有产出、有编号，界面上今天**没有"复制它的命令"这一动作**。
- 不做的后果：你复制出来一大段滚动日志，其中最有用的那行命令反而没在里面。

**8.4 面板里那一格终端。**〔根本没做〕
- 别人怎么做：右侧栏可以打开、恢复、控制一个真的交互命令行标签页；顺带一提，他们官方那张"包地图"漏掉的 2 枚里正好有这一枚（另一枚是账号页）。
- 我们现在是什么样：面板那五块固定内容里**没有终端这一块**；而他们的名册里"侧栏终端"是一整包（我这一腿**没深读那一包**，只登记存在）。
- 不做的后果：**它跑了一个需要你插话的命令（装依赖问到 Y/N、SSH 要口令、`npm login`），你今天只能看输出不能插手。** 上一版我写过"git 绝不弹隐藏口令框把人挂住"，那是**别弹**；这一条是**万一非弹不可，得有地方弹**。

**8.5 状态图标：同一枚共享组件、三种状态一个名字、每行给状态预留同宽。**〔这是给界面那支的话，不是我们的活〕
- 别人怎么做：全程用**具名的矢量图标组件**，**没有一枚字符图标**（这跟我们选图标库的方向一致）；状态点是**共享组件**、只有 进行中／完成／静止 三态；**每一行都给状态图标预留同一 14 像素的列宽**。
- 我们现在是什么样：球那侧有 20 种状态各有自己的颜色字（是**颜色**，不是形状）；界面那一支要不要用同一枚共享状态点、要不要留同宽，**不在我这支的射程**，也不该由我拍。
- 不做的后果：⚠ 我们的球有 **20 种状态**、而且（上一版第九节说过）**全靠颜色区分**。他们这个"同一形状、同一位置、不只靠颜色"是**同一问题的同一种解法**，值得点名给界面那一支。

**8.6 抄他们那一秒一跳的计时之前，先看这条警告。**〔抄法警告，不是缺口〕
- 别人怎么做（这就是他们的形状）：耗时是"已结束累计 +（现在 − 本轮起点）"，而"现在"由每秒一跳的定时器推。⚠ **这是墙钟差**，而我们禁的是"用墙钟差实现超时"——显示不算超时，但**我们的写手照这一形抄，那道门会把它读成违规形状**。
- 我们现在是什么样：**名册行今天没有计时**（第三节差一），所以这不是"已经踩了"，是**"补计时那一跳时一定会踩"**。
- 可用的替代是他们自己的分层：**存储侧本来就是"事件起点／终点／累计"，那一秒一跳只在显示那一层。** 照这个分层抄就不撞（我这腿确认了编排者早先自裁的"不许照抄"是对的，并给出可用替代）。
- 不做的后果：**写手照他们那一形抄，代码是对的、门禁会把它读成违规形状，一整腿白跑**——这种返工本可以靠这一段避免。

## 九、你不在这台机器前：手机／IDE 那两壳教会我们的四条规则

先给一句**推翻性的事实**：上一版我按"桌面＋网页"来数 OpenChamber。**错了，它有四条一等界面**：桌面程序、网页／可装成应用、**手机壳**（带推送、锁屏小组件、点通知直达）、**VS Code 扩展**。以后凡是"人家只是桌面套了个网页"这类话，都不要再说。

但**它的手机审批那一跳，恰好否掉了两种常见想象**：

**9.1 审批的正确形状是三段，不是"通知上带个批准钮"。**〔根本没做〕
- 别人怎么做：① 服务端事件触发（就四类：干完了／出错了／要回答／要批准），给手机发推送，**推送内容刻意写得空泛**——固定标题＋会话名，**不带模型名、不带项目、不带消息正文**；② 点推送 → **直接跳到那一条会话**（冷启动时这个意图**先存住不丢**）；③ 进了 App **照常弹可交互的批准卡**——手机复用整套对话界面。
- ⚠ 两个都不对的读法：**不是**"推送上点一下就批了"，**也**不是"手机上只读不给批"。他们**故意不用推送按钮**，为的就是把"批准必须带着上下文"这件事保住。
- 我们现在是什么样：我们全仓没有推送／中转这些东西；面板那根"推送"其实是**同一个进程里 Go 发给网页的一条消息**，出不了这台机器。
- 不做的后果：**你合上盖子出门，审批就永远悬着。** ⚠ 而且**别把这一格写成"抄个托盘 toast 就算对齐"**——他们那套的前提是"有一台一直可达的服务器"；我们是单机，服务器＝本机，所以我们的真问题是**"进程还在、人走了"这一格谁来答**。这一问和我们那枚"到点该问的没人能答"是同一枚。

**9.2 "正在看就别吵"这道门，判据该抄这句。**〔根本没做〕
- 别人怎么做：门**只盯"有没有任何一个能答的端正在被用"**，**从不盯手机自己**。而且他们踩过坑之后**主动放弃了**那道"问客户端你在不在"的门（注释逐字：那道门在网页容器里有竞态），改成"**永远发、让操作系统压前台**"。另外手机在前台时永远不弹横幅。
- 我们现在是什么样：**没有这个门，也没有"谁在看"这个概念**（全仓搜不到对位的包）；今天只有一枚"是不是在后台"的粗判据。
- 不做的后果：⚠ 这是**别人用一次事故换来的教训**。我们做通知那一格时如果自己去问"面板开着吗"，就会**把同一枚竞态重新发明一遍**。

**9.3 "有几件事在等你"这枚数——我们今天数据源是现成的。**〔做了但没人接上〕
- 别人怎么做：应用图标角标＝**"自上次打开以来累计的、不同的提醒条数"**（不是会话数），服务端算、三路信号清（可见性心跳＋打开会话＋发消息都算"人在用"）。锁屏小组件上的橙色未读点用的是**和会话侧栏完全同一个判据**："有没看过的，而且（不是子任务，或者子任务的提醒开关开着）"。
- 我们现在是什么样：托盘图标在、球在，**没有"数上去"那一跳**；但**"等批准队列的长度"这个数已经存在**。
- 不做的后果：这一格是**最便宜的"人不在场"改进**：数不用造，载体（球）天然比角标强。⚠ 顺带一句反面参照：那家做了 VS Code 扩展的，**在编辑器里一枚状态栏条目都不做**（全仓搜"创建状态栏项"0 命中），所有状态信息留在自己的界面里——**说明"常驻视觉件该摆什么"这件事，连做了四端的人都在克制**。

**9.4 点通知要能直达那一条会话：得先有一张"意图词表"。**〔根本没做〕
- 别人怎么做：一个自定义协议前缀，后面挂**7 种意图**，解析是纯函数、**认不出来就返回空、不抛错**；冷启动那份意图**先存住**等界面起来再放。
- 我们现在是什么样：搜"点通知跳到哪一条"这一族 **0 命中**，设计文件里也没有自定义协议这一条；而会话编号体系是有的（**那张意图词表的形状可以直接搬**）。
- 不做的后果：⚠ 光做"发通知"没用——**点了跳不过去的通知，只会让你更烦**。这一格是 9.1 的前置。

**9.5 各家订阅额度那一屏：这才是"点开设置一堆东西"里最实用的一屏。**〔根本没做〕
- 别人怎么做：在 VS Code 扩展里做了约 **20 家**编码订阅的用量窗口（日／周／月／本轮／会话五类），带**重置倒计时**、余额、消费上限；实现层是宿主进程直接读各家接口和本地凭据文件。
- 我们现在是什么样：面板规划里只有成本那一页的一行数（多少字、多少钱），**搜"配额"在两份相关设计文件里 0 命中**；而我们的服务商适配层已经在仓里（**数据有处可来，缺那一屏**）。
- 不做的后果：你手里同时有两三家订阅时，**"这个月还能用多少、什么时候重置"今天只能去各家网页翻**。⚠ 值得抄的是**数据形状**（用了百分之几／多少秒后重置／窗口多长），不是那 20 家。

**9.6 关掉界面不等于关掉任务——这一格对我们是〔根本没做〕。**
- 别人怎么做：整套设计的前提是"任务本来就在服务器上跑"；手机上的终端关掉，**跑的是活动服务器那边的会话，界面关闭只是渲染器脱手，服务器侧留在原地可重连**。
- 我们现在是什么样：我们的进程就在本机，所以**不能照抄那套**；但**"界面关掉只是渲染器脱手，任务留在原地"这一条对我们完全成立**。
- 不做的后果：⚠ 这条其实是第一节第 7 条那四条规则里最狠的一枚：**我们今天的形态（任务在主进程里）意味着"关面板 = 可能丢正在跑的活"。** 这一格要和"会话那本账"（第三节差二）一起做。

**9.7 那三件"看起来该抄其实不该抄"的**（详见第十三节）：多服务器实例管理、扫码配对、锁屏小组件。前两件的前提是"要连到某台机器"，我们没有；第三件在 Windows 上**没有等价物**。
- 不做的后果：**没有后果，这一格是刻意不做**；能从他们那儿搬过来的只有它背后的设计形状（一份"把当前状态抓成一包"的函数＋靠事件驱动刷新＋**不联网也能更新的推送件**）。理由给在第十三节。
- 别人怎么做：手机壳里做"连到哪台机器"的管理、扫码配成一对、锁屏和桌面上摆小组件（有的还做了一枚"待处理几件事"的数字圆件）。

- 我们现在是什么样：**这三件一件都没有，而且按我们的形态不该有**——没有"另一台要连"、没有第二个终端要配对。
**9.8 ⚠ 一处"他们的文档自己就是矛盾的"，记下来当我们的存在理由。**
- 不做的后果：**没有后果，这一格是刻意不做**；能迁移的只有它背后的设计形状（一份"把当前状态抓成一包"的函数＋靠事件驱动刷新＋不联网也能更新的推送件）。理由给在第十三节。
- 别人怎么做（这就是他们的现状）：两份文档互相打脸——一份写着安卓推送"未实现"，另一份＋安卓的清单文件＋已提交的配置文件说已实现。- 我们现在是什么样：我们的规矩恰好相反——**每条结论带行号、台账只追加不删、那份克隆"没有提交历史"这件事写进派单**。
- 不做的后果（这里是别人的教训对我们的用处）：⚠ 这不是我们的缺口，是**"没有提交历史时行号是唯一凭据"这件事的现例**，反过来证明我们那套"台账只追加、每条带时刻"是必要的。**引旧账必须带时刻**（第一节第 1、3 两条就是我自己犯的）。

## 十、给它的是什么材料、这条消息是谁发起的、插件能动哪些东西

**10.1 "这一条是谁发起的"必须是一等业务数据，不是日志里的自由文本。**〔根本没做〕
- 别人怎么做：一张 **13 个来源**的词表：网页接口／定时／任务／后台任务／团队／线程目标／问卷／通讯／代码评审／问候／三个聊天软件频道。这个字段进了**每一条投递的入参**。会话"当前什么状态"（5 值）和"这是哪一类会话"（6 值）**分成正交两轴**，不许混。
- 我们现在是什么样：最接近的东西管的是**内容**从哪来（这段文字读自哪个文件），**不是**这条**触发**从哪来。
- 不做的后果：**定时唤起的那一次，和你在球上按的那一次，在它眼里一模一样。** 出了事（比如"半夜它自己动了我的文件"）你**分不清是哪条路进来的**——而这类事故最后一定被问"到底是谁触发的"。

**10.2 提醒不该一条条写死在代码里，该是一条链＋一份配置。**〔根本没做这一层〕
- 别人怎么做：**30 枚**提醒块构造函数挂在一条链上，可以按名字开、**按框架开**、还有一档"要紧的"（关掉全量提醒时**要紧的照跑**，但要紧的**也走同一份白名单**，不是特权通行）。⚠ **每个名字有自己的频控**：一份区间表＋冷却＋间隔轮数；语义钉得很清楚——**"没配"＝全跑（老行为）**、**"配了空表"＝全关（安全兜底）**、**"配了名字"＝只跑这些**。记忆提醒是**指数退避**：第 10 轮第一次提，你不理它就到 20、再 40 封顶；**你要是照做了就保持节奏**；那份按会话的状态**还带容量上限**（怕它无限长）。同一份内容备了**浓、淡两版**按需选。⚠ 其中一枚最漂亮：**密钥变量那一枚只报变量名、绝不报值**，而且三种语义分清——没接线就闭嘴、库是空的也闭嘴（"没东西好提醒"）、非空才渲染，**且只在第一轮或者名字集合变了时渲染**。
- 我们现在是什么样：**只有一种提醒**（重复调用那一条），直接注入在环路里；**按名字频控／冷却／退避的表 0 命中**（我搜的就是这一族词）。
- 不做的后果：我们要加"计划提醒／记忆提醒／身份提醒"这类东西，**今天只能一条条写代码**；他们是一条链一份配置。⚠ 这条对我们还有第二重意义：**我们的刹车提醒是硬编码在环路里的**（4.7 那格说的防污染后缀也该从这一层出）。

**10.3 反悔之后，名字不许回收。**〔根本没做〕
- 别人怎么做：把"工具名字"当**永久资源**管：两级分配（服务器段＋工具段）、**落盘＋加锁＋原子替换**、状态带版本号。三条语义逐字写着：**"绝不从公开名字里推身份"／"删掉的名字仍然占着它那一段，新来的来源不许继承旧名"／"磁盘型实例在独占事务里刷新之后才分配新名"**。名字长度也有具名上限（整名 80、服务器段 48）。
- 我们现在是什么样：我们今天刚钉的是**同一轮之内不许撞名**；**跨时间（删掉之后重建）不许继承旧名这一条，全仓没有对应物**。
- 不做的后果：**你卸载了一枚插件，又装上一枚新插件、它取了同一个名字 ⇒ 它继承了旧插件的授权和缓存。** 这是我们那类"名字当身份用"的病根。

**10.4 谁的技能被谁的盖掉了，要有一份"败者名单"。**〔根本没做〕
- 别人怎么做：技能分**六个来源层**（项目／工作区／智能体／全局／用户／内置），每层可带优先级；同名遮蔽时**败方带着"为什么输"和"赢家的位置"一起存**，整份名册带版本号和生成时刻，**"谁的被谁的盖掉了"是可查询、可带版本的一等业务数据**。⚠ 另外他们把"根目录之外的符号链接"**默认关**，只有登记成兼容来源的才允许（注释逐字写着这件事）。
- 我们现在是什么样：我搜"败者／遮蔽"，**只搜了两个目录，0 命中**——⇒ 这条只能写成"**限定范围内为 0**"，不能写"全仓为 0"。
- 不做的后果：技能／插件一多，**"我明明写了它为什么不用"就是这枚病**，而今天没有一份能查的"谁盖了谁"。（顺带：他们那份"技能目录变了要去监听"是**去抖 1 秒**＋显式关闭＋按"目标路径＋根编号"组合键复用监听器——这一形我们已经有了。）

**10.5 插件能钩哪些点、以及"不许动哪些东西"这张红线清单。**〔根本没做这一层；开不开属你一句话〕
- 别人怎么做：**11 个钩子点**：会话开始／会话结束／用户提交输入／工具用之前／**批准请求**／工具用之后／子代理开始／子代理停止／停止／压缩之前／压缩之后。会话开始那枚还带六种来历（首次／恢复／清空／压缩／分叉／插件刚被激活）。钩子的执行体是**子进程**，而它那份 Windows 取消作业正是我们要的：**Windows 用 `taskkill /pid … /T /F` 杀整棵树**、隐藏窗口、**只给 500 毫秒排空**；输入 1MB 硬闸、输出超 64KB 直接判"输出不合法"并杀进程、理由 4096 字上限；**普通事件预算 15 秒，而"会话结束"那种收尾事件只给 3 秒**；六种失败结局，每枚都带**"哪个插件的哪份文件、第几个声明"**——出错能定位到具体哪一行；观测回调**不许改动裁决**（注释逐字："观测绝不能改变权限裁决"）。
- ⚠ 而对我们最值钱的，是他们**把"插件可以改哪些东西"写成了一张清单**，我们照着挑哪些不许：能不能**替用户批准**（他们能，注释逐字写着"明确的允许**就不给用户看界面**"）；批准范围是"只放行普通档"还是"任何要问的都放行"；能不能**改工具入参**；能不能**改"模型看到的工具结果"**（他们允许，但**账上必须留原文**、且必须声明格式归属）；能不能**改权限规则**（加／换／删规则、**换档（那份档位词表里含"绕过权限"）**、**扩大允许目录**，且**宿主必须整条原子应用**、有一档"故意不许被宿主持久化"）；能不能**停掉正在跑的 agent**；能不能给用户塞一条消息／压掉输出／给下一步模型一条反馈（后者注明**"绝不是硬停"**）；能不能**写终端控制序列**（他们有一枚专门的白名单函数把关）。
- 我们现在是什么样：搜那 11 个钩子名 **0 命中**；全仓"hook"这个词的 76 处命中**逐名全是系统语义**（键盘钩子／关机钩子／桥回调），**没有一枚是"插件事件名册"**。
- 不做的后果：**这既是优势也是缺口**——攻击面小（插件碰不到决策），但**插件也不能做合规预处理**（比如"任何要发给外部网络的文本先脱敏"）。⚠ **要不要开这一层要你一句话，不是我自己能排的活。**

**10.6 同一枚危险输出，按"来源"选择性禁用，而不是全局允许或全局禁止。**〔思路已有，缺机读标签〕
- 别人怎么做：代码里逐字一行——**自家格式的钩子，带权限更新的直接丢弃**；只有兼容格式才被解析翻译，而且逐类校验（换档要查词表、扩目录要单独走一条）。
- 我们现在是什么样：**禁令写了，但没有机读的来源标签**（哪一路进来的这条输出，今天不是一个字段）；所以"这一枚危险输出来自哪一层"目前只能靠代码位置推断。
- 不做的后果：⚠ 这与我们那条禁形（**不许由面板侧来源给出最严档的"允许"**）用的是同一种思路——**来源决定它能不能产生授权**。我们已经写了这条禁令，**但缺他们那种机读的来源标签**（三个来源格式＋"哪个插件拥有这台服务器"必须由宿主证明才限定名字）。**这条直接对我们那枚"面板侧来源的允许没有仪器覆盖"的悬案有用。**

**10.7 "这个入口不许从网络请求里取调用者身份"——要写在类型上，不是靠字段名约好。**〔根本没做〕
- 别人怎么做：有一份**只有 12 行的边界声明文件**，逐字两句："调用方控制的取消上下文；**不接受网络身份或 HTTP 头**。"／"会话帧在进程内消费。"**他们不是"给面板加一枚来源字段"，而是把"进程内入口"单独立成一份文件，并在类型文档里禁止它携带网络身份。**
- 我们现在是什么样：我们的桥**存在**，方法名册和能力标注**在文档里写着**，但那个类型今天**还不叫这个名字**（另一处注释里还写着"未来的某某桥"）。⇒ 老实说：**我们的白名单管"能调哪些方法"，他们那 12 行管"这个入口不许从哪儿取调用者"。两样不互相替代。**
- 不做的后果：⚠ **枚方法名对上但身份来源没管住**，就还是"网页自己伪造了一次用户批准"那条路。

**10.8 挂起的"等人回答"该续上还是作废——这里有一条外部先例，但我不替你拍。**〔待定案项，只登记〕
- 别人怎么做：有一份**独立的窄入口**专门做这件事，注释逐字："**恢复一份被持久化下来的'等用户输入'等待。这是一条窄的内部准入缝：它绝不进普通队列，而那个请求号就是它的可重放身份。**"
- 我们现在是什么样：**这一格是空白**——待定案清单里明写着"等批准时系统挂起（倾向作废判拒绝）"，代码里既没有窄入口，也没有重放身份。
- 不做的后果（准确说是"这一格我们本来就没定案"）：**这正是我们那枚"等批准时系统挂起该怎么办"（倾向作废并判拒绝）的第二个可选答案**——两条路都满足"不复活陈旧的批准请求"，但他们多给了"**挂起的用户输入可以被合法续上**"这一格。**我们的定案不改；这只是一条现成先例。碰这条属"没定义就停下来问"，我不自行填。**

**10.9 目标要拿短码钉住，"账过期了"要分三种原因。**〔根本没做，便宜〕
- 别人怎么做：目标语句用 **sha256 摘要**钉死；"这笔用量为什么过期"是**三枚分开的名字**：目标没了／纪元换了／目标文本改了——**不共用一个"过期了"**。
- 我们现在是什么样：**"目标文本变过"这一维没有**（目标不落库、也没有纪元号），过期原因也就没得分开——**这条几乎不要钱，越早在册越省事**。
- 我们现在是什么样：**"目标文本变过"这一维没有**（目标不落库、也没有纪元号），过期原因更没得分开——**这条几乎不要钱，越早在册越省事**。
- 不做的后果：**"目标被改过一次"和"目标被删了"混成同一条，回来续跑时就分不清该接着算还是该重算。**

## 十一、Windows 这台机器上的破事

**11.1 双击打开的程序拿不到你在终端里有的东西。**〔根本没做，但有现成算法〕
- 别人怎么做：桌面程序启动时**主动去系统那儿把完整环境清单取回来**，四级回退（先叫一个 PowerShell 问、再叫另一个、再退到系统目录里的全路径、最后用 `cmd` 问一遍），拿回来的结果用**不可打印字符切分**（防路径里的空格把结果切碎），隐藏窗口、10 秒超时，实在找不到再问一句"你到底装在哪儿"。
- 我们现在是什么样：算法这一整套**没有**；我们只有"从快捷方式启动时补全 PATH：半个"那一格——也就是**关键路径偶尔能碰上、碰上不了就说找不到**。
- 不做的后果：**"装了 CLI 但 Wisp 说找不到"这类幽灵 bug 会一直躺在工单池里查不出根**——而且我们规划里的模型下载和插件定位（都要在"计划任务／服务"这种没有终端环境的语境里找可执行文件）**一定会撞上同一枚坑**。

**11.2 我们领先他们的两格（必须反向标）。**〔反向〕
- 别人怎么做：他们的权限层能把删除命令改写成"丢进回收站"，但**Windows 的 `del`/`rd`/`Remove-Item` 三条还没接上改写通路，注释里写着"接通之前最安全的策略是硬拒"**；越界防护是"遇符号链接直接抛＋解到底再验仍在根内"；密钥**落明文**、全仓没有系统密钥接口。
- 我们现在是什么样：**我们已经走系统调用做可撤销删除，并且回读回收站里的恢复记录来证明它真进了回收站**（注释逐字："这条路永远走不到直接删除：删掉不等于进回收站"）；越界防护**更严且已成规矩**（文件系统决策只许在一处做，接合点／重解析点各有专门测试）；**密钥走系统加密存放，在仓里**。
- 不做的后果（这里是"别做错方向"的后果）：⚠ 如果差集清单把这三格写成"别人有我们没有"，**我们就会去补一堆本来已经更强的东西，还可能顺手把强的那面改松**。唯一值得抄的是他们那三枚**临时文件名的忽略名单形状**（可以直接当测试夹具）和那条**纪律**："每个存储面写明哪一层绝不出现密钥"。

**11.3 他们给"面板能调哪些方法"提供了一份现成的对照集。**〔给拍板用的现量，不是缺口〕
- 别人怎么做：网页那一侧没权限干的事，全部由**宿主进程代做**，一共 **32 种消息**：文件系统 10 种（增删改查／执行／在资源管理器里显示／挑选）；**git 24 种**（暂存／取消暂存／**逐块应用**／提交／推／拉／取回／五种工作树操作／**生成 PR 描述**／冲突详情）；开文件、开对比视图；往工作区加文件夹；**代接那条一直冒字的连接**（重连 3 次、从 1 秒起指数退避、**20 秒没有新内容判停滞**）。
- 我们现在是什么样：我们那张"面板可调用哪些方法"的定稿表**至今没拍**（属"没定义即停"里标着阻塞的那一枚）；桥本身在、方法名册在文档里写着，**但那份白名单今天还没有定稿**。
- 不做的后果：⚠ 这条的价值是**省一次凭空设计**——32 个名字是别人定过稿的候选集，可以逐条对着我们那张内置工具权威表比。**但别把它当"要抄的功能"**：它是给拍板用的现量。

**11.4 各家屏幕的兼容账，他们全写在文档里。**〔这是治理参照，不是功能〕
- 别人怎么做：把踩过的坑逐条写死——安卓原生那条连接不稳 ⇒ **手机原生流式锁死一种协议、禁用另一种**；某网页内核要 111 版以上才认某个颜色函数；iOS 模拟器构建时临时剥掉某个识别库；推送环境按配置文件自判、并把环境随令牌一起上报。
- 我们现在是什么样：我们有"没定义就停下来问"这套规矩，也有台账（只追加、每条带时刻）——**这恰好是他们缺的那面**；⚠ 但"某块界面在哪个系统版本上会怎样"这类**实测账**，我们只在键盘那一格有（84 枚候选组合的占用实测）。
- 不做的后果：⚠ **反面教训更响：他们没写的那部分（安卓推送到底实现没有）现在已经没人知道，两份文档互相打脸。** 我们的 WebView 版本、麦克风权限、开机自启这些将来都要留这种账，否则三个月后无人可问。

## 十二、我建议按这个顺序做

排序尺子只有三条：**① 今天就在咬人的先修**、**② 只缺一条线的先接（最便宜）**、**③ 后面所有东西都踩在上面的先做**。不是按"哪个看起来像功能"排。

**第一枚：你按了停止，要同时告诉模型（并把停止做成两击）。**
只缺的那一半在第四节 4.13。今天就能自己做完、**不碰任何要你一句话的东西**、而且它是**正确性**不是手感。⚠ 顺序上它必须第一，因为它最便宜又最要命。

**第二枚：刹车降到"每一次动作"，并补两类信号＋两张豁免。**
第 4.1、4.2、4.3、4.5、4.6、4.7 这一族一起做（它们是同一次改动），**外加 4.5 那张"哪些重复是合法的"豁免表**——这条现在是"正常轮询被误判成跑飞"，而**校验型子代理天生会撞刹车**（差七），所以这颗雷必须在子代理多跑起来**之前**拆。落点就在同一个文件，不需要常驻进程、不需要网络。

**第三枚：中文的字数换算改成"锚定服务商给的真值、只估尾巴、宁高不低、并标明这数是估的还是真的"。**
6.2 加 6.3 加 6.4 是一枚票的三半，拆开做会做两遍。**这是本轮唯一一枚"今天就在咬人、而且咬的是长中文会话"的技术风险。**

**第四枚：任务的持久账本——送达那一列、"丢了"这个状态、"取消失败"那枚旗、每枚任务自己带花费。**
6.6、6.7、6.8 三枚一起做（它们是同一张表）。⚠ 判据里必须写死那条陷阱：**抄状态不抄旗标＝造"账上已取消、实际进程还在"的假终态**；以及"**只有那一轮确实没活下来的精确证据才允许判丢，很久没动不算**"。这一枚也是第三节"差一（名册行给不出钱和时间）"和"差二（那本账本）"的**共同前置**。

**第五枚：子代理"点进去那一页"需要的可导航身份（把子代理当一份会话，不当一条流）。**
第三节差三。⚠ 它**碰那张面板可调用方法表**（今天有"列名册／看详情"，**没有"把这枚会话装进某一格"**），所以这一枚要你先一句话才能动；而且**要一次给两个落点**（主区顶替＋右侧另开一格）＋**同一枚不许开两页**（差三末）。
⇒ 顺带把 **第七节 7.5 那枚"接线"**（改了键、产品不重启不生效）夹带走掉——它只要补一行装配，是这份表里第二便宜的。

**第六枚：让界面画名册。**
这不是我们的活，是第三节 3.3 那一跳（**两枚键**）。我们的产码已经就绪、红字已经写明只有一跳。⚠ 这一枚排在第五枚之前还是之后取决于界面那一支的节奏，但**它排不到很后面**：今晚三层入库之后，**"子代理上不上界面"这一格只剩这一跳**。

**第七枚：把定时与后台的恢复形状补上。**
6.9（重启后逐枚重登记＋**"恢复来的档期先只登记不执行"**）、6.10（五种排队结局＋**按事件来源过滤哪些"错误"可以排空队列**）、6.11（排队中那次也能撤＋跳过要说得出是哪一种）。
⇒ 这一枚是**"你不在场"这一类事故的主要来源**，也直接对上我们那句"定时交给系统"里从没讨论过的那几维。

**第八枚："要回答"那条通路（它反问你一句）。**
5.1，和 5.2 那枚"界面上没有'就这一次'这个动词"**一起做**——因为它们其实是同一枚缺口的两面：那家把"要批准"和"要回答"做成**同一套依次问过去的机制**，只是包裹里的内容不同。**我们该复用已有的那条作用域路由和关联号，而不是新造一条通路。**
⚠ 这一枚里**有一格必须你先答**：5.2 末那句"允许这个出口该落在哪一层"。**我不动它，只把它摆在这儿。**

**第九枚：授权宽度候选＋"一直允许会把哪条规则存下来"印出来。**
5.3。它把三个按钮升级成可审计、可回滚、可统计的对象，**而且"第一档永远是最窄的"那条兼容律是别人已经踩出来的**，我们直接接。

**第十枚：拒绝的三种心智＋双语表＋"新判据必须有文案"的编译期钉子。**
5.4。成本极低（一张表＋一枚"少写就编译不过"的检查），收益是**模型知道该换路还是该放弃**。⚠ 顺手把 5.5 那枚"**现场没人能答就直接拒绝**"一起收了——它同时补上深度睡眠那一格和子代理卡住那一格。

**第十一枚：出问题时的证据两件。**
6.1（每一轮"实际喂给模型什么配置"的证据件）＋ 4.12（策略版本号）。⚠ 这两枚都是**越晚补越贵**：现在不补，三个月后想复盘"那一次为什么这样"，**数据已经不在了**。4.11（离线回放算"这道护栏省了多少"）排在它后面，因为它是前两者的消费者。

**第十二枚：Windows 那枚找不到的 PATH（11.1）。**
排在第十二不是因为它不重要，是因为它**独立、小、随时能插队**。如果哪天你在界面上问"我装了的命令它怎么说找不到"，这枚立刻提到第一。

## 十三、我不建议抄的，以及为什么（只给形状级理由）

**1. 多服务器实例管理、扫码配对、加密中继、隧道。**
他们的产品形状是**"一套服务端摊到多端"**，所以"先回答连到哪台"是他们的第一屏。我们是**本机单用户常驻**：抄过来会把"球一直在那儿"这个前提换成"你得先连上一个东西"。**形状不合，不是能力不行。**

**2. 手机壳、VS Code 扩展宿主本身。**
壳不该抄（同上）。⚠ 但**里面那四条规则要抄**（见第一节第 7 条）：别拿"问客户端在不在"当门、断线先对齐权威态、冷启动意图先存住、孩子未完不宣布完成。
**上一版我把这一整块划掉了，那是划宽了。**

**3. 整套停靠／分栏引擎。**
那家自己写着这是**"内部引擎、导出的东西不作任何版本承诺"**——抄它的接口＝签一份随时会变的合同。
⇒ 我们真正要的那一格只是**"两个落点＋同一枚不许开两页"**（第三节差三）。这一格可以抄；**整个引擎不抄**。

**4. 扩展市场／插件 SDK 那一整套。**
他们那个内置扩展登记表**是空的**（清单文件里逐字是空数组，README 自己承认"目前为空"），而且扩展面板**在 VS Code 和手机里明确不支持**。⇒ **"看着一堆内置，其实零内置"。** 这一包的真交付物是**信任与授权模型**（保留命名空间、授权由声明推导、禁用状态与数据分离），它对应的是我们"插件信任"那一格，**不是对应"应用商店"**。

**5. 把 git 工作树当成"会话的一种运行位置"。**
他们有一份词表允许"新工作树／已有工作树"作为会话去处，还带分支和母仓路径。⇒ **这和我们一条硬规矩直接冲突**（绝不在仓库目录内建工作树或检出）。**要么明确写"不接"，要么单独议**，不许在实现里顺手接进来。

**6. "没有检查器的工具默认放行"那一档。**
他们最坏情况比我们宽（我们无判定器就升到最严档）。⚠ **别把"他们档位更多"读成"他们更安全"**——真正值得抄的是他们兜那一级的那两枚机关（**未注册工具先按"参数里能不能提出路径意图"过一遍；写类工具提不出路径意图时反而要问**），不是那一级本身。

**7. 云端二次判定照抄。**
理由见 5.10：**延迟账和隐私账不能互相冒充对方**。要抄就得二选一并明写代价。

**8. "通知上带批准按钮"。**
那家故意不用推送按钮，注释和文档都写着理由：**批准必须带着上下文给人看**。⇒ 谁提议"我们在托盘或通知上加两个按钮就齐了"，请让他先读第九节 9.1。**这一条我上一版写得不够狠**（我当时把"批准按钮长在托盘菜单里"当成要抄的亮点——那是对的形状（面板没开也能批），但**不是"点通知直接批"**，两者差别就是 9.1）。

**9. 定时"错过的档期补跑"当已解决问题。**
两边都没有。我们把"定时交给系统"那套落地时，那一格要自己拍（上一版第九节我写过"每个周期任务只补最近一次错过的"，那是**我们的要求**，不是别人的现成品）。

**10. "每日摘要"那个名字。**
它是**记忆整理**（默认关、实现文件在这份公开副本里还不存在），**不是决策汇报**。别人转述"MiniMax 有日报"时，请让他读第一节第 8 条。

**11. 一次性搬他们的界面分包结构（那 52 个包）。**
那家的分包是为"**界面是一等公民的扩展点**"这个前提服务的（49 枚靠"注册进某个位置"活着——他们把界面摆成一个个插座，谁的控件往哪个插座里插都行）。我们的形态是**一块面板＋一颗球**，不是可扩展的工作台。⇒ **抄具体控件（第三、八、九节那些），不抄那套装配结构。**
